# 数据库设计

SQL 建表与测试数据的唯一执行源为 [schema.sql](../backend/src/main/resources/db/schema.sql)。本文件解释字段约束，避免多人各自修改 SQL。

| 表 | 职责 | 关键约束 |
| --- | --- | --- |
| `user` | 账号资料 | `username` 唯一；密码只存 BCrypt 哈希 |
| `document` | 当前文档状态 | `content` 与 `revision` 必须用同一条 UPDATE 原子更新 |
| `doc_operation` | 全量操作审计 | `(doc_id, revision)` 唯一，防止重复提交 |
| `doc_snapshot` | 定期快照 | 按 `(doc_id, revision)` 查询恢复基线 |
| `doc_collaborator` | 协作者权限 | `(doc_id, user_id)` 唯一；1 只读，2 可编辑 |

`document.content` 保存 Quill Delta JSON，空文档必须为 `{"ops":[{"insert":"\\n"}]}`。Redis 只保留热数据与近端操作历史；MySQL 才是持久化事实来源。

恢复时以最近快照（或 `document.content`）为基线，按 revision 顺序重放后续 `doc_operation`。任何写入逻辑都不能把内容版本和 revision 拆成两次更新。
