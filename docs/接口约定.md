# 接口约定（Day 1 冻结版）

所有 REST 响应遵循同一外层结构。成功为 `code: 0`；HTTP 状态码与业务码同时表达错误，401/403/404 按 HTTP 语义返回。

```json
{ "code": 0, "message": "success", "data": {} }
```

除注册、登录外，REST 接口均须带 `Authorization: Bearer <token>`。时间统一为 `yyyy-MM-dd HH:mm:ss`。客户端不得依赖未在本文件声明的字段。

## 错误码

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | 400 | 参数错误 |
| 401 | 401 | 未登录或 token 失效 |
| 403 | 403 | 无权访问 |
| 404 | 404 | 文档/资源不存在 |
| 409 | 40901 | 文档忙（稍后重试） |
| 409 | 40902 | 客户端版本超前 |
| 409 | 40903 | 版本历史过旧，需全量同步 |
| 500 | 500 | 服务器内部错误 |

## 1. 注册

**POST** `/api/auth/register`

```json
{ "username": "student01", "password": "123456", "nickname": "小明" }
```

`username` 3–50 字符且唯一，`password` 6–64 字符。成功 `data`：`{ "id": 1, "username": "student01", "nickname": "小明" }`；用户名重复返回 400。

## 2. 登录

**POST** `/api/auth/login`

```json
{ "username": "testA", "password": "123456" }
```

成功 `data`：

```json
{ "token": "eyJ...", "user": { "id": 1, "username": "testA", "nickname": "测试用户 A", "avatar": null } }
```

账号或密码错误返回 401。密码仅传输和校验，响应绝不返回密码字段。

## 3. 文档列表

**GET** `/api/doc/list?page=1&size=20&keyword=`

`page` 默认 1；`size` 默认 20，最大 100；`keyword` 按标题模糊匹配。

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 2,
    "list": [{ "id": 1001, "title": "项目需求说明书", "ownerId": 1, "ownerName": "测试用户 A", "parentId": 0, "updateTime": "2026-09-14 15:30:00" }]
  }
}
```

## 4. 新建文档

**POST** `/api/doc`

```json
{ "title": "未命名文档", "parentId": 0 }
```

标题默认“未命名文档”，`parentId` 默认 0。成功 `data` 返回新建文档摘要：`id`、`title`、`ownerId`、`parentId`、`updateTime`。

## 5. 重命名文档

**PUT** `/api/doc/{id}`

```json
{ "title": "新的文档标题" }
```

成功 `data` 返回 `{ "id": 1001, "title": "新的文档标题", "updateTime": "..." }`。不存在返回 404，无权修改返回 403。

## 6. 删除文档

**DELETE** `/api/doc/{id}`

逻辑删除，成功响应为 `{ "code": 0, "message": "success", "data": null }`。不存在返回 404，无权删除返回 403。

## 7. 获取文档详情（编辑器交界）

**GET** `/api/doc/{id}`

成功 `data`：

```json
{
  "id": 1001,
  "title": "项目需求说明书",
  "content": { "ops": [{ "insert": "\\n" }] },
  "revision": 0,
  "ownerId": 1,
  "permission": 2,
  "updateTime": "2026-09-14 15:30:00"
}
```

`content` 必须是 Quill Delta JSON 对象而非字符串；`permission` 为 `1`（只读）或 `2`（可编辑）。`revision` 和 `content` 必须来自同一版本。

## 8. 搜索

**GET** `/api/search?q=协同&page=1&size=20`

`q` 必填，按标题及正文检索。成功 `data`：

```json
{ "total": 1, "list": [{ "id": 1001, "title": "项目需求说明书", "snippet": "支持多人实时<strong>协同</strong>编辑", "updateTime": "2026-09-14 15:30:00" }] }
```

`snippet` 允许含 ES 高亮标签，前端渲染前必须做白名单处理。

## 9. 上传图片（编辑器交界）

**POST** `/api/upload/image`，`Content-Type: multipart/form-data`，字段名 `file`。

限制：仅 JPEG、PNG、GIF、WebP；单文件不超过 10 MiB。成功 `data`：

```json
{ "url": "http://localhost:9000/collab/images/2026/09/uuid.png", "name": "diagram.png", "size": 204800, "contentType": "image/png" }
```

`url` 必须是浏览器可访问的 `minio.public-endpoint` 地址，不能返回 Docker 内部主机名 `minio:9000`。

## 10. WebSocket 协同（负责人实现）

**GET（升级 WebSocket）** `/ws/collab?token=<JWT>`

浏览器原生 WebSocket 无法设置 `Authorization` 请求头，token 固定使用 query 参数。消息均为 JSON，字段名使用 camelCase。

客户端加入文档：

```json
{ "type": "join", "docId": 1001, "clientId": "uuid", "lastRevision": 0 }
```

服务端全量同步：

```json
{ "type": "sync", "docId": 1001, "revision": 0, "content": { "ops": [{ "insert": "\\n" }] }, "users": [{ "userId": 1, "nickname": "测试用户 A", "color": "#2563eb" }] }
```

提交操作：

```json
{ "type": "op", "docId": 1001, "clientId": "uuid", "baseRevision": 0, "op": { "ops": [{ "retain": 1 }, { "insert": "A" }] } }
```

确认仅用于 pending 出队，客户端**不得**二次应用 `op`：

```json
{ "type": "ack", "docId": 1001, "clientId": "uuid", "revision": 1 }
```

远程操作：

```json
{ "type": "op", "docId": 1001, "originClientId": "other-uuid", "revision": 1, "op": { "ops": [{ "retain": 1 }, { "insert": "B" }] } }
```

光标广播：`{ "type": "cursor", "docId": 1001, "clientId": "uuid", "index": 3, "length": 0, "color": "#db2777" }`。客户端节流至 50 ms，且仅位置变化时发送。

服务器错误：`{ "type": "error", "code": 40903, "message": "版本过旧，请重新同步文档" }`。收到 40903 后客户端应重新 join 获取全量内容。
