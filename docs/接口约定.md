# 接口约定（Day 1 冻结版）

所有 REST 响应遵循同一外层结构。成功为 `code: 0`；HTTP 状态码与业务码同时表达错误，401/403/404 按 HTTP 语义返回。

```json
{ "code": 0, "message": "success", "data": {} }
```

除注册、登录外，REST 接口均须带 `Authorization: Bearer <token>`。时间统一为 `yyyy-MM-dd HH:mm:ss`。客户端不得依赖未在本文件声明的字段。

## 错误码

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | 400 | 参数错误 |
| 401 | 401 | 未登录或 token 失效 |
| 403 | 403 | 无权访问 |
| 404 | 404 | 文档/资源不存在 |
| 409 | 40901 | 文档忙（稍后重试） |
| 409 | 40902 | 客户端版本超前 |
| 409 | 40903 | 版本历史过旧，需全量同步 |
| 500 | 500 | 服务器内部错误 |

## 1. 注册

**POST** `/api/auth/register`

```json
{ "username": "student01", "password": "123456", "nickname": "小明" }
```

`username` 3–50 字符且唯一，`password` 6–64 字符。成功 `data`：`{ "id": 1, "username": "student01", "nickname": "小明" }`；用户名重复返回 400。

## 2. 登录

**POST** `/api/auth/login`

```json
{ "username": "testA", "password": "123456" }
```

成功 `data`：

```json
{ "token": "eyJ...", "user": { "id": 1, "username": "testA", "nickname": "测试用户 A", "avatar": null } }
```

账号或密码错误返回 401。密码仅传输和校验，响应绝不返回密码字段。

令牌必须有已签名且未到期的exp；默认由JWT_EXPIRE_HOURS=24配置。服务端HTTP与WS握手验证签名/期限，并对照账号凭据版本。WS只保存已验证的到期时间，不保存令牌；每条客户端消息及每次正文转发前检查期限，到期返回现有error401并1008关闭，不再处理新操作或转发新正文。无会话期限元数据也拒绝。完全空闲连接不承诺在精确到期毫秒主动关闭，但后续消息/心跳/转发均检查；在期限前已获授权的请求可能完成，不回滚已提交事务。客户端保存未确认草稿，正常重登后先确认恢复。既有协议字段保持兼容，没有新增客户端消息类型。

## 2a. 当前账号与密码维护

以下接口均需Bearer登录。客户端不传目标用户ID；GET/PUT只返回当前账号的id、username、nickname、avatar，不返回密码哈希或凭据版本。

| 方法 | 路径 | 请求与结果 |
| --- | --- | --- |
| GET | `/api/account/me` | 返回当前账号公开资料 |
| PUT | `/api/account/me` | `{ "nickname": "新昵称" }`；去除首尾空白，1～50字符，无控制字符；返回新资料 |
| POST | `/api/account/password` | `{ "currentPassword": "原密码", "newPassword": "新密码" }`；成功data:null |

用户名不可修改。新密码非空白、6～64字符、UTF-8最多72字节，不能与原密码相同。原密码错误或非法新密码返回400，不退出当前登录；原密码输入最多64字符、72字节。改密事务锁定本人账号，同时更新BCrypt哈希和递增数据库credential_version；JWT新增整数credentialVersion。每个REST请求、WS握手及每条WS消息/正文转发校验当前数据库版本。旧无版本令牌按0兼容，仅账号尚未改密时接受。

事务提交后Redis内部account_changed通知关闭各实例旧连接，客户端沿用error401与1008关闭；新版本连接不被迟到通知关闭。通知失败仍由后续请求、心跳及转发检查拒绝旧版本；数据库故障返回5xx（握手503），不误判401。昵称在新连接使用最新数据库资料。改密不改变文档、权限或本地草稿；客户端需重新登录并确认恢复草稿。此前已经授权的在途请求可能完成，取消或改密不回滚已提交修改。

## 3. 文档列表

**GET** `/api/doc/list?page=1&size=20&keyword=&scope=all`

`page` 默认 1；`size` 默认 20，最大 100；`keyword` 去除首尾空白后最多 200 字符，按标题包含匹配（`%`、`_` 为普通字符）。`scope` 默认 `all`，可选 `owned`（自己创建）或 `shared`（其他所有者共享给自己）；未知分类返回 400。所有分类都只返回当前有权访问且未删除的文档，按更新时间、ID 降序分页。摘要不读取或返回正文、revision；权限在列表查询内取得，无逐篇补查。

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 2,
    "list": [{ "id": 1001, "title": "项目需求说明书", "ownerId": 1, "ownerName": "测试用户 A", "parentId": 0, "updateTime": "2026-09-14 15:30:00", "permission": 2, "isOwner": true }]
  }
}
```

## 4. 新建文档

**POST** `/api/doc`

```json
{ "title": "未命名文档", "parentId": 0 }
```

标题默认“未命名文档”，`parentId` 默认 0。成功 `data` 返回新建文档摘要：`id`、`title`、`ownerId`、`parentId`、`updateTime`。

## 5. 重命名文档

**PUT** `/api/doc/{id}`

```json
{ "title": "新的文档标题" }
```

成功 `data` 返回 `{ "id": 1001, "title": "新的文档标题", "updateTime": "..." }`。不存在返回 404，无权修改返回 403。

## 6. 删除文档

**DELETE** `/api/doc/{id}`

逻辑删除，成功响应为 `{ "code": 0, "message": "success", "data": null }`。不存在返回 404，无权删除返回 403。

### 6.1 回收站与恢复（2026-10-03 新增）

**GET** `/api/doc/trash?page=1&size=20`：仅返回当前所有者的已删除文档，`page` 从 1 开始、`size` 为 1～100；`data` 为 `{ "total": 1, "list": [{ "id": 1001, "title": "项目需求说明书", "deletedAt": "2026-10-03 19:00:00" }] }`。不返回正文或成员列表。

**POST** `/api/doc/{id}/restore`：无请求体；只有所有者可恢复，成功返回活动文档摘要。无登录 401，非所有者或不存在 404。恢复保留正文/revision/原成员权限/尚存历史，只改变删除标志和更新时间；已经活动的自有文档返回摘要，不修改后续编辑。已清理普通历史不会重建。

删除事务提交后发布文档范围的 permission 通知，每个实例重新核对当前数据库权限；已删除文档的在线 owner/member 收到 permission=0 并关闭连接（1008）。通知不携带正文，延迟到达时以当前状态为准，不误撤销已恢复文档。REST 详情/历史/搜索和新 WS join 均拒绝已删除文档访问。没有永久删除或自动清空接口。

### 6.2 文档导入导出（2026-10-03 新增）

**POST** `/api/doc/import`，`multipart/form-data`：必需文件字段`file`，可选字符串`title`（最多200字符）。支持非空UTF-8 `.txt`（BOM去除、CRLF/CR转LF、补末尾换行）或CoPage `.json`，文件与正文副本限制1 MiB。成功data为新文档摘要，新所有者为当前账号、revision=0、同事务保存版本0快照；不复制成员、历史或文件里的身份字段。缺file/无效编码/结构/格式/超限返回400，无token401。

CoPage副本结构为`{ "format": "copage", "version": 1, "title": "标题", "content": { "ops": [...] } }`。正文最多10000片段，只允许insert文本/HTTP(S)图片、支持的Quill格式与安全链接，必须以换行结束；retain/delete、未知嵌入、可执行链接及非法属性拒绝。同格式的相邻文本在线性时间合并后保存，避免大量碎片反复拼接。

**GET** `/api/doc/{id}/export?format=copage`，另支持`format=txt`。每次核对可见权限，普通只读成员也可导出；撤权403、文档删除404。成功data为`{ "filename": "标题.copage.json", "mediaType": "application/json;charset=utf-8", "content": "文件文本", "revision": 0 }`，前端将content生成下载文件。filename移除路径/控制字符，正文与revision取自同一数据库行；副本最多1 MiB且不含成员、历史或身份元数据。txt去除格式、图片以地址文字保留；JSON保留格式与图片URL，不打包图片，不是服务器备份。

### 6.3 创建独立副本（2026-10-06 新增）

**POST** `/api/doc/{id}/copy`，需当前可见权限，只读成员也可调用。body可省略或为`{}`；可选`{ "title": "副本标题" }`。省略/null标题使用“原标题 的副本”，超长默认标题安全截断到200个UTF-16单位；显式标题去首尾空白后须为1～200个单位，空标题或超长返回400。

成功data：`{ "id": 1002, "title": "副本标题", "sourceRevision": 8 }`。sourceRevision指锁定来源时读取的已保存版本，不是新文档的版本；新文档归当前用户、parentId=0、revision=0，正文及版本0快照同事务写入，建立独立搜索索引。不复制原权限、历史、本地草稿或图片文件；图片保留URL，后续正文与来源独立。

未登录401、无当前权限403、来源已删除/不存在404；在来源行锁内校验权限，与现有成员修改锁一致。站内复制不经过1 MiB文件转换，保留来源的完整已存正文，不放宽正文2 MiB或操作4 MiB限制。每次成功请求创建独立新文档，不提供跨请求幂等；请求结果不确定时先检查列表再重试。

## 7. 获取文档详情（编辑器交界）

**GET** `/api/doc/{id}`

成功 `data`：

```json
{
  "id": 1001,
  "title": "项目需求说明书",
  "content": { "ops": [{ "insert": "\n" }] },
  "revision": 0,
  "ownerId": 1,
  "permission": 2,
  "updateTime": "2026-09-14 15:30:00"
}
```

`content` 必须是 Quill Delta JSON 对象而非字符串；`permission` 为 `1`（只读）或 `2`（可编辑）。`revision` 和 `content` 必须来自同一版本。

2026-10-03 追加字段：列表/新建摘要同时返回 `permission`（1/2）、`isOwner`（布尔）；详情追加 `isOwner`。原有字段及其含义保持不变。前端据此显示操作入口，服务端仍逐次检查权限。

### 7.1 协作者管理（2026-10-03 新增）

以下四个接口仅允许未删除文档的所有者操作；普通协作者即使有编辑权也返回 403。所有者不出现在成员列表，也不能通过这些接口更改自身权限。

| 方法 | 路径 | 请求 / 成功 data |
| --- | --- | --- |
| GET | `/api/doc/{id}/collaborators` | `[{ "userId": 2, "username": "testB", "nickname": "测试用户 B", "permission": 1 }]` |
| POST | `/api/doc/{id}/collaborators` | 请求 `{ "username": "testB", "permission": 1 }`，成功 `data: null` |
| PUT | `/api/doc/{id}/collaborators/{userId}` | 请求 `{ "permission": 2 }`，成功 `data: null` |
| DELETE | `/api/doc/{id}/collaborators/{userId}` | 成功 `data: null` |

用户名去除首尾空白，必须是已注册账号；不存在返回 404。权限只允许 1（只读）或 2（可编辑）；重复添加返回 400，不会覆盖现有权限，应改用 PUT。更改/移除非成员返回 404；修改所有者或非法参数返回 400。响应不包含密码、token 或全站用户目录。

权限事务提交后经 Redis 通知所有实例。服务器转发每条 op/cursor/presence 前仍从 MySQL 校验接收者权限；撤权者仅收到权限通知后连接关闭，不再收到正文。成员降为只读时，无未确认编辑的页面立即停止输入并继续接收远端内容；有未确认修改则暂停协同并保留本地草稿，不自动丢弃或重发。重新添加已移除成员后，成员需重新打开文档。

文档所有者始终具有可编辑权限且只有所有者可以删除；`doc_collaborator.permission=2` 的协作者可查看和重命名，`permission=1` 只能查看。文档列表只返回当前用户拥有或参与的未删除文档。没有权限访问现存文档返回 403；已删除或不存在返回 404。

## 8. 搜索

**GET** `/api/search?q=协同&page=1&size=20`

`q` 必填，按标题及正文检索。成功 `data`：

```json
{ "total": 1, "list": [{ "id": 1001, "title": "项目需求说明书", "snippet": "支持多人实时<strong>协同</strong>编辑", "updateTime": "2026-09-14 15:30:00" }] }
```

`snippet` 中的原文 HTML 已转义，服务端只插入 `<strong>` 高亮标签；前端若按 HTML 渲染仍须做白名单处理。搜索权限以 MySQL 当前可见文档为准，ES 索引不授予权限。

摘要高亮在原文上按Unicode大小写无关的字面关键词定位，不将用户输入解释为正则表达式，也不使用可能变长的小写副本坐标。正文存在字面匹配时优先正文，否则展示标题摘要；上下文截取避免拆开UTF-16代理对。此高亮不改变ES词项检索规则，也不承诺组合emoji/所有字素簇均按整体截取。

## 9. 上传图片（编辑器交界）

**POST** `/api/upload/image`，`Content-Type: multipart/form-data`，字段名 `file`。

限制：仅 JPEG、PNG、GIF、WebP；单文件不超过 10 MiB。成功 `data`：

```json
{ "url": "http://localhost:9000/collab/images/2026/09/uuid.png", "name": "diagram.png", "size": 204800, "contentType": "image/png" }
```

`url` 必须是浏览器可访问的 `minio.public-endpoint` 地址，不能返回 Docker 内部主机名 `minio:9000`。

## 10. WebSocket 协同（负责人实现）

2026-10-03 追加权限通知：`{ "type": "permission", "docId": 1001, "permission": 1 }`；0 表示访问被撤销或文档已删除，1 为只读，2 为可编辑。`sync` 和已 join 的 `pong` 追加当前 `permission`，用于首次同步、重连及心跳补偿。已有 OT/revision/ack 字段保持原义。

**GET（升级 WebSocket）** `/ws/collab?token=<JWT>`

浏览器原生 WebSocket 无法设置 `Authorization` 请求头，token 固定使用 query 参数。消息均为 JSON，字段名使用 camelCase。

客户端加入文档：

```json
{ "type": "join", "docId": 1001, "clientId": "uuid", "lastRevision": 0, "syncId": "sync-uuid" }
```

有未确认操作时，join 还需携带 `pendingOpId`、`pendingBaseRevision`、`pendingOp`，三者必须是首次发送时的原始请求。服务端会核对持久化收据及请求指纹；同一 opId 不能用于不同编辑。`syncId` 用于关联请求和响应，最多 128 字符；`clientId` 最多 255 字符。

服务端同步（快照读取、会话注册和发送均在同一文档锁内完成）：

```json
{ "type": "sync", "docId": 1001, "syncId": "sync-uuid", "fromRevision": 0, "revision": 0, "content": { "ops": [{ "insert": "\n" }] }, "historyComplete": true, "history": [], "pendingCommittedRevision": null, "users": [{ "userId": 1, "nickname": "测试用户 A", "color": "#2563eb" }] }
```

提交操作：

```json
{ "type": "op", "docId": 1001, "clientId": "uuid", "opId": "op-uuid", "baseRevision": 0, "op": { "ops": [{ "insert": "A" }] } }
```

确认仅用于 pending 出队，客户端**不得**二次应用 `op`：

```json
{ "type": "ack", "docId": 1001, "clientId": "uuid", "opId": "op-uuid", "revision": 1 }
```

远程操作：

```json
{ "type": "op", "docId": 1001, "originClientId": "other-uuid", "opId": "other-op-uuid", "revision": 1, "op": { "ops": [{ "insert": "B" }] } }
```

客户端光标消息：`{ "type": "cursor", "docId": 1001, "index": 3, "length": 0, "visible": true }`；失焦时发送 `visible: false`。服务端从已认证的会话填充身份并广播：`{ "type": "cursor", "docId": 1001, "clientId": "uuid", "index": 3, "length": 0, "visible": true, "nickname": "小明", "color": "#db2777" }`。客户端 50 ms 节流，位置不变时不重复发送；聚焦期间每 20 秒保活一次。远端显示超过 60 秒未更新的光标会过期，断线/重同步时先清除旧光标。光标是临时状态，不推进文档 revision。

服务器错误：`{ "type": "error", "code": 40903, "message": "版本过旧，请重新同步文档" }`。收到 40903 后客户端应重新 join 追赶；40904 表示 opId 被用于不同请求，应保留本地编辑并停止自动重放。

`opId` 最多 128 字符。重试必须沿用原始 opId、baseRevision 和 op，不能把经过本地 OT 变换的操作当成原请求重发。收据与正文、版本、日志同事务持久化；重复请求只补原 ack，不再修改正文或广播。为兼容旧客户端，服务端仍接受不带 opId 的操作，但这种请求不具备幂等重试保证。

`history` 按 revision 连续排列，元素形如 `{ "revision": 1, "op": { "ops": [{ "insert": "A" }] } }`，范围为 `(fromRevision, revision]`。单次同步最多携带 2000 条；超过 2000 条且所需历史在保留范围内时，`historyPaged=true`，随后分批恢复。历史缺失、客户端版本超前或低于保留起点时，`historyComplete=false` 且无法分页恢复。客户端有本地 pending/buffer 时必须保留它们并按历史 OT 追赶；`pendingCommittedRevision` 对应自身操作，只确认而不重复应用。历史不完整时保留本地草稿并转只读，不能直接用 content 覆盖。没有未确认编辑时可加载快照。

分页请求为 `{ "type":"history_request", "docId":1001, "syncId":"sync-uuid", "afterRevision":0, "throughRevision":2005 }`；响应 `history_page` 携带 docId、syncId、fromRevision、toRevision、revision（固定目标）、permission、history。每页最多 256 条，SQL 按累计操作字节限制普通页约 1 MiB；首条较大合法操作单独返回。客户端验证每页连续性，超时重试相同页，忽略旧页；完成前只修改工作副本，并暂存后续广播。保留起点推进导致缺口时明确失败。WS 文本消息上限 8 MiB，操作上限 4 MiB，当前正文上限 2 MiB。

### 协同消息补充约定

以下消息沿用同一个 `/ws/collab` 连接。`ping/pong` 和 `presence` 已由服务端支持；`reset` 仍是协议预留。

| 方向 | 消息 | JSON 示例 | 语义 |
| --- | --- | --- | --- |
| 客户端 → 服务端 | 心跳 | `{ "type": "ping" }` | 检查连接是否仍可用 |
| 服务端 → 客户端 | 心跳响应 | `{ "type": "pong", "docId": 1001, "revision": 12 }` | 已 join 时附服务端当前版本；客户端落后时重新 join，不能仅凭 pong 推进本地版本 |
| 服务端 → 客户端 | 在线状态 | `{ "type": "presence", "docId": 1001, "users": [{ "userId": 1, "nickname": "测试用户 A", "color": "#2563eb" }] }` | 加入、离开或超时后发送当前在线用户全集；同一用户只出现一次 |
| 服务端 → 客户端 | 强制重同步（预留） | `{ "type": "reset", "docId": 1001, "revision": 12, "content": { "ops": [{ "insert": "正文\n" }] }, "users": [] }` | 有未确认编辑时保留草稿并停止自动替换；仅无本地编辑时可加载新快照 |

`content` 与 `revision` 必须对应同一版本。`presence` 不改变版本。客户端按 revision 去重并检测缺口，不能假定跨实例广播与直接 ack 总是按序抵达；跳号时暂停发送并重新 join。旧连接提交后，新连接可能收到同 clientId/opId 的广播，应按自身确认处理。心跳版本检查用于补偿 Redis Pub/Sub 单条广播丢失。

## 8. 历史版本（2026-10-03 新增）

仅所有者可调用 `GET /api/doc/{id}/history/retention`，返回 enabled、days、maxOperations、maxBytes、protectedDocument、currentRevision、minimumRevision、proposedMinimumRevision。手动清理为 `POST /api/doc/{id}/history/compact`，body 为必填非负 expectedRevision、beforeRevision；起点必须高于旧起点且不超过当前版本。当前版本变化返回 40902，受保护文档返回 403。成功返回新起点；正文和重要版本保留，起点之前的普通版本不能恢复。自动维护默认关闭，详见[历史版本与保留策略](历史版本与保留策略.md)。

`GET /api/doc/{id}/history?beforeRevision=...&limit=20` 返回 currentRevision、minimumRevision、list、namedVersions、nextBeforeRevision。列表按 revision 倒序，用 nextBeforeRevision 继续取更早版本，limit 为 1～100。初始版本为 0；重要版本单列展示，最多 20 个且正文总量不超过 32 MiB。

`GET /api/doc/{id}/history/{revision}` 返回 revision 与原始 Delta content，复用当前文档访问权限；删除或撤权后拒绝访问。历史正文从最近基准快照及连续操作还原，遇到缺口明确失败，不返回部分正文。

仅所有者可调用 `PUT /api/doc/{id}/history/{revision}/name`（body: name，1～100 字符）、`DELETE /api/doc/{id}/history/{revision}/name` 和 `POST /api/doc/{id}/history/{revision}/restore`。恢复 body 为 expectedRevision（必填非负数）和 requestId（必填，最多 128 字符）；响应 revision、applied。恢复正文生成新 revision 并广播正常 op；不倒退版本号、不改写旧日志。当前版本不等于 expectedRevision 时 HTTP 409/code 40902；同 requestId 改变请求目标时 code 40904；超出保留范围或历史缺口时 code 40903。网络失败后的重试复用同 requestId 和 expectedRevision。

## 9. 内置文档模板（2026-10-03）

`GET /api/doc/templates` 需要登录，返回模板数组：id、title、description、content（只含内置框架的 Delta）。目前提供 meeting、project、notes，分别为会议纪要、项目计划、学习笔记，不读取用户文档。

`POST /api/doc` 的已有 title/parentId 保持兼容，新增可选 templateId；不传时创建空白文档，传未知 ID 返回 400。使用模板且不传 title 时默认模板标题。新文档仍为 revision=0；模板初始内容及 revision=0 快照在同一事务写入，后续历史恢复 0 回到模板原文。每篇拥有自己的正文和权限，没有模板共享编辑、用户模板管理或匿名分享。


## 标题与元信息通知（2026-10-04）

- `GET /api/doc/{id}/metadata`：需当前可见权限，返回 `data: { id, title, updateTime }`，不返回正文。未登录401、无权403、删除/不存在404。
- `PUT /api/doc/{id}`：沿用已有重命名请求和响应，可编辑成员/所有者允许；只读拒绝。标题写入成功后才在事务提交后广播，不增加正文revision。
- WS 新增 `{ "type": "metadata", "docId": 1001 }`，仅为失效通知，不携带旧标题或正文。广播通过Redis到所有实例，各接收连接先重新检查权限；前端另取metadata，并取消旧请求。首次同步和每次恢复ready时也重新读取，避免断线漏掉通知。
- 通知故障不撤销已经提交的改名；页面重连时重读，HTTP失败提供标题专属重试，不更改正文协同状态。
- `/api/doc/list` 现有keyword参数用于标题包含匹配，按普通文字处理`%`、`_`，不作为SQL通配符；权限范围和分页约定不变。
- 分享为前端文档URL，不新增匿名访问或自动授权接口。正文保存提示依据待确认pending/buffer、输入法、上传和连接状态；“已连接”与“所有修改已保存”分别显示。

## 实时编辑格式边界（2026-10-05）

实时编辑op和join.pendingOp使用相同产品格式校验：最多10000片段，insert只支持非空文字/HTTP(S)图片；retain/delete必须是正整数，不能用浮点或字符串转换。未知嵌入、未知字段及非法链接/格式返回400且不推进revision。retain属性中的null用于移除已有格式；delete不能携带属性。图片可保留alt（最多512字符，无控制字符）、width/height（字符串1～10000或1%～100%）；编辑、预览与CoPage副本支持范围一致。当前阶段不提供video/formula嵌入。

服务端在OT处理后的最终正文上校验末尾换行，不能提交空Delta正文、删除最后换行或在它后面追加非换行内容；返回400且正文/revision/操作日志/收据不变。合法的全文替换保留末尾换行即可。

## 客户端心跳超时（2026-10-05）

客户端每20秒发送ping，为该次回复设置15秒超时。收到pong先清除连接层超时，再转交编辑器处理版本和权限；组合输入的业务消息暂存不阻止清除超时。超时则废弃旧连接、暂停编辑、保留未确认操作并重连；浏览器后台节流可能延长检测时间。离线、断线和显式关闭均清除相关计时器，旧连接事件按连接身份忽略。消息格式与版本/权限字段不变。

## 工作台概览（2026-10-09）

**GET** `/api/doc/workbench`，需要当前Bearer登录，不接受userId或客户端角色。成功data包含ownedCount、sharedCount及recent数组；recent至多6篇，按updateTime/id倒序，沿用文档列表摘要字段id、title、ownerId、ownerName、parentId、updateTime、permission、isOwner，不返回正文或revision。

数量分别表示本人未删除的文档和他人明确授予当前账号访问的未删除文档；不包含无权限、回收站、未来项目或小组默认授权。无数据返回两数量0及空数组；读取故障仍返回错误，不能以空数组冒充成功。每次读取以当前文档权限为准，打开条目仍由文档接口与WebSocket独立校验。

## 工作台组织概览（2026-10-09）

**GET** `/api/workspace/overview`，沿用Bearer鉴权；只使用可信UserContext身份，没有userId或角色切换参数。匿名401。data含activeGroupCount、personalProjectCount、groupProjectCount、personalTemplateCount、pendingInvitationCount、invitations。
