# 分工说明

| 区域 | 负责人 | 不可跨界修改的原因 |
| --- | --- | --- |
| `backend/**/ot`、`backend/**/collab` | 负责人 | 前后端 OT 与 WebSocket 时序必须一致 |
| `frontend/src/editor`、`src/ot`、`src/ws`、`pages/Editor.jsx` | 负责人 | 同上 |
| `backend/**/user`、`document`、`search`、`storage` | 队友 A | 按接口约定填充业务实现 |
| `pages/Login.jsx`、`DocList.jsx`、`Search.jsx` | 队友 A | 将当前假数据替换为 REST 调用 |
| `docs/qa`、测试记录、答辩材料 | 队友 B | 保持测试与实现职责独立 |

推荐分支：`feat/collab-core`、`feat/backend-biz`、`docs/qa-materials`。`main` 只接收完成验证后的合并结果。
