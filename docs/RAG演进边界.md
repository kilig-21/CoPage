# RAG 数据预留与接口边界（CODI-93）

本文仅说明 CoPage 将来接入 RAG 时可以复用的数据与必须保持的边界，**不是已经上线的 AI 功能或冻结接口**。是否启用外部模型、选择哪家服务、是否允许文档内容离开本机/自有服务器，均待项目负责人决定；决定前不新增 AI 凭据、向量库、对话接口或后台上传任务。

2026-10-03 按本地交付范围完成数据预留和边界核对：当前继续使用已有 MySQL/ES 数据，不启用 AI 问答，不向第三方发送文档。CODI-93 完成的是本文件所述的演进预留验收；实际模型选型、数据出口及问答功能是后续扩展，不是本次本地运行的前置条件。

## 当前可复用的事实来源

| 数据 | 当前来源 | RAG 使用边界 |
| --- | --- | --- |
| 文档正文、标题、版本 | MySQL `document.content`（Quill Delta JSON）、`title`、`revision` | 同一行读取内容与版本；仅从文本 `insert` 提取正文，跳过图片等嵌入对象及其 URL |
| 操作历史与快照 | MySQL `doc_operation`、`doc_snapshot` | 用于恢复和审计，不把旧版本自动混入当前问答上下文 |
| 当前访问权限 | MySQL `document.owner_id`、`is_deleted`、`doc_collaborator` | 检索与引用前按当前登录用户重新校验；索引里的旧权限绝不能授权 |
| 全文检索 | Elasticsearch `collab_documents` | 只是可重建的标题/正文检索副本，不是最终权限或最新版本的事实来源 |

Redis 的热状态和近端操作历史不能充当持久知识库；MinIO 当前只负责图片存储，不自动解析图片内容。现有 ES 索引不包含向量，也没有分块、嵌入或生成能力。

### 数据预留如何复用

- 当前 `document.id + revision` 已能标识提交版本，`content` 与 `revision` 由同一行读取；不用提前增加无消费者的向量字段。将来若需要分块，另表以 `docId + revision + chunkNo` 标识，纯文本偏移以同版本抽取结果为准，不把 Quill 嵌入对象的长度当成正文字符数。
- 所有者和协作者权限仍由已有表决定；[协作者接口](接口约定.md#71-协作者管理2026-10-03-新增)只允许所有者操作。任何新增检索或问答入口都复用 JWT/UserContext，并在取候选、发送模型和返回引用前重新检查权限与删除状态，不复制长期有效的权限到索引。
- 将来的响应引用至少带 `docId`、`revision`、片段位置和来源；不能把客户端未确认草稿作为已保存文档，不能把 `doc_operation`/`doc_snapshot` 的旧版本悄悄拼入当前上下文。
- 当前 `/api/search` 继续是全文搜索，`/ws/collab` 继续服务 OT；不改变现有成功/错误响应，不把新问答伪装成这两个接口的行为。未来 REST 请求/响应需另写版本化契约并取得负责人对实际功能的确认。

## 拟议的后端边界（未实现）

1. **抽取与分块**：在已提交的 MySQL 文档版本上提取纯文本，按 `docId + revision + chunkNo` 标识片段。写入任何检索副本前，检查文档仍存在且未删除；内容更改、改名、删除时更新或移除过期片段。分块与嵌入可异步进行，但对外必须标明索引版本，不能把滞后结果伪称最新内容。
2. **检索**：请求携带现有 JWT；候选片段可以来自 ES 或未来的向量库，但返回前必须用 MySQL 当前权限过滤文档 ID，并核对版本。失去协作者权限或文档被软删除后，即使索引还未清理，也不能返回正文、片段或引用。
3. **生成**：仅把已授权的片段交给模型，结果至少标明引用的 `docId`、`revision` 和片段位置；答案不是文档事实来源。模型错误、超时或索引未就绪时应显式失败或降级到普通检索，不能绕过权限或无提示地编造引用。
4. **数据出口**：模型调用、日志和缓存不得默认记录完整正文、JWT 或图片访问地址。若选择第三方模型，先确定用户授权方式、数据保留期限、密钥管理与删除/撤权后的清理策略，再实现实际上传。

以上是模块职责，不是新的 REST 路由或数据库迁移。将来若新增接口，应另写版本化请求/响应示例和错误码，经负责人确认后再更新[接口约定](接口约定.md)；不得改变现有 `/api/search` 的权限语义或 WS 的 OT/revision 协议。

## 实际启用 AI 前由负责人确认

- RAG 是仅本机/自托管，还是允许把文档片段发送到第三方模型？若允许，使用哪家服务、哪些环境可用？
- 是否需要图片 OCR、历史版本问答、跨文档问答？默认均不做。
- 未完成索引更新时，问答应阻止、降级到普通检索，还是允许显示带明确旧版本标记的结果？
- 引用粒度、内容保留期限和用户撤权/删除后的索引清理时限。

这些选择仅在以后实际启用 AI 时需要；在权限、删除、版本滞后和模型出口测试通过之前，不能声明 AI 问答功能完成。
