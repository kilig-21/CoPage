# CoPage 本地使用指南

本地运行即可使用注册登录、文档管理、成员权限、实时协同、图片上传和全文搜索。不需要域名、服务器、Vercel 或 AI 模型账号。最近本地验收记录见[交付验收清单](交付验收清单.md)。

当前候选范围、证据和待验收项见[持续产品交付复核](产品交付质量复核.md)；历史阶段的数字和完成结论仅代表当时版本。

## 副本创建结果待确认

副本显示结果未确认时，原标题和原创建标识会保留。可以在弹窗“确认原副本”，也可关闭弹窗后从“我的文档”的“待确认的副本”继续；编辑器同样提供入口。刷新或重新登录原账号仍可找回，确认始终发送同一次请求，不按同名文档猜测成功，也不自动新建。已创建的私人副本独立于来源；来源后来删除或撤权，仍可确认原结果。尚未创建的请求继续检查当前来源权限，来源不可读时会拒绝，原记录保留。

这些记录只在当前账号、服务和浏览器标签内保存来源编号、标题请求、创建标识和时间，不保存正文。确认成功才结束记录；清理失败会明确说明已创建，先核对我的文档。关闭标签、清除站点数据或换浏览器可能失去记录，此时先查已有文档和回收站再决定是否重做。升级前只保存UUID的旧记录不能自动列出；来源仍可打开时，重新提交完全相同的标题请求可沿用原标识。

## 项目资料读取与重试

项目列表、小组资料和已打开的项目详情可以分别重试，其他已成功读取的资料可继续使用。小组资料未就绪时先恢复读取再创建项目；修改弹窗遇到临时读取失败会保留输入，重试成功后才允许保存。自动回退有效页码不会关闭同一项目的表单。

写操作显示结果未确认时，“核对操作结果”读取原项目或原文档关联的当前状态；普通刷新、筛选、关闭弹窗不代替核对。关联被重新加入时会提示新关联，不自动删除。暂时无法核对会保留原目标；持续不可读时可明确确认“结束本次等待”继续其他工作，原结果仍未知，请自行查看原资料后再决定是否重做。

创建项目可以明确“确认原创建”，找回或完成同一次请求，不按同名项目猜测成功。原名称、简介、归属、请求标识和时间保存在当前浏览器的localStorage，按当前账号与后端服务隔离；刷新或重登原账号后，从“待确认的创建”继续。正文、密码、令牌不存入该记录。需要继续其他工作时可“稍后确认”，仅解除界面等待，记录保留，不自动重试或撤销。确认仍检查当前项目访问权限，401/403/404或存储失败都保留原记录；确认成功后再次主动创建才使用新标识。清除站点数据、换浏览器或同时在多个标签首次创建相同资料时，应先查看已有项目；不承诺跨标签的首次准备原子锁。

改资料、归档、恢复、加入及移出的待核对目标仍仅在当前标签内存按账号保留，站内离开再返回或正常重登原账号可继续；整页刷新或关闭标签后须自行核对原项目与文档关联。它们不自动重试，也不具有创建回执的持久保证。

## 启动

已有本项目服务运行时可直接打开前端，不重复启动同一端口。若启动报告端口占用，先核对实际运行进程；不要沿用旧日志里的进程号去停止服务。

准备 Docker Desktop、JDK 21、Maven 3.9+ 和 Node.js 22.12+，确保 `docker`、`java`、`mvn`、`node`、`npm` 在 PATH 中可用。具体版本与端口见[README](../README.md#本地运行)。

### Windows 日常启动入口

先启动 Docker Desktop，再双击项目根目录的 **[启动CoPage.cmd](../启动CoPage.cmd)**。等待窗口显示后端、前端“可用”及基础服务“已就绪”，打开 [CoPage](http://localhost:5173) 即可使用。窗口会保留启动结果或错误；按任意键关闭窗口后，已启动的服务继续运行。

重复双击会复用已有本项目服务，不会重复启动或停止其他项目。入口仍调用原有 `scripts/local.ps1`，不改系统执行策略，不删除数据或重设密码；仍需先具备上文列出的本地环境。出现 Docker 未启动等错误时，按窗口说明处理后再双击重试。

习惯使用终端时，也可在项目根目录执行：

```powershell
Set-Location C:\Users\Lenovo\Desktop\ALLCODE\CoPage
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local.ps1 start
```

首次会下载缺少的镜像及锁文件中的前端依赖；随后构建当前 Java 源码和前端，后台启动后端 8080 与前端 5173 生产预览。显示两端可用和基础服务就绪后，打开 [CoPage](http://localhost:5173)。启动成功后可以关闭终端；修改源码后需停止旧服务再启动，不会热更新。生产构建没有“填入演示账号”按钮，可直接输入 `testA / 123456` 登录。

```powershell
# 只读检查；可追加 -Json 供脚本读取
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local.ps1 status
# 只停止本入口启动并核对身份一致的前后端
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\local.ps1 stop
```

重复 `start` 会复用已有同项目服务；IDEA 或其它终端启动的进程不会被接管，`stop` 会保持它们原样。其它项目占用端口时会拒绝启动，请先核对原进程。入口核对 PID、启动时间、命令与路径，不仅凭旧进程号停止服务；Windows PowerShell 5.1 和 PowerShell 7 都支持。命令中的执行策略参数只作用于当前命令，不修改系统策略。

Docker 引擎未启动时会报错，请启动 Docker Desktop 后重试。已有 `.env` 保留，首次缺失才复制示例；后端子进程获得 Compose 有效配置中的本地连接地址、凭据和历史保护参数，前端使用本机 HTTP/WS 地址。不会持久修改全局环境变量，也不会给已有数据库重设密码。仅支持本地 default profile、localhost:5173；其它 profile/origin 请使用对应部署流程。

运行记录、安装/构建和应用日志、npm 缓存位于被 Git 忽略的 `.copage-local/`。失败时错误会给出日志路径；只回滚本次新启动且身份核对一致的应用进程，保留 Docker、现有服务和数据卷。不要在服务运行中删除运行记录，否则入口不能再识别它负责的进程。`stop` 不停止 Docker，不删除文档、图片、日志或数据卷。

### 分窗口开发方式

需要热更新或在 IDEA 调试时，保留以下方式。先通过原启动方式停止占用同端口的服务，以下三个 PowerShell 窗口都进入项目根目录：

```powershell
Set-Location C:\Users\Lenovo\Desktop\ALLCODE\CoPage
```

窗口一启动基础服务：

```powershell
docker compose up -d
docker compose ps -a
```

MySQL、Redis、RabbitMQ、Elasticsearch 应为 healthy，MinIO 运行，minio-init 成功退出 0。保留已有数据卷，不重新初始化数据库。

窗口二运行当前源码后端：

```powershell
mvn -f backend/pom.xml spring-boot:run
```

看到后端在 8080 启动后，窗口三启动前端：

```powershell
# 首次使用或依赖变更时执行；已有依赖可跳过
npm --prefix frontend ci
npm --prefix frontend run dev
```

打开 [http://localhost:5173](http://localhost:5173)。Vite 将 API 与 WebSocket 代理到 8080。可选 Docker 后端位于 8082；它不会自动替代 Vite 使用的 8080，修改代码后也不会自动更新旧镜像。

若 Maven 命令未加入 PATH，可在本机使用：

```powershell
& 'D:\Coding\Marven\apache-maven-3.9.16\bin\mvn.cmd' -f backend/pom.xml spring-boot:run
```

关闭前端/后端窗口前用 Ctrl+C 正常停止。需要停止本项目基础服务时可执行 `docker compose stop`；数据保留，下次 `up -d` 即可继续使用。

## 浏览器存储暂时不可用

首次打开时看到“浏览器存储暂时不可用”，请允许当前站点使用Cookie和站点数据，再点击“重试存储访问”。仍无法读取时会继续提示；成功后在原地址继续登录或打开文档，不必换链接。

已有身份、草稿和标签信息不会被这次检查清除。不要为了重试清空站点数据；允许读取后，有未确认草稿的文档仍需选择恢复或稍后处理。存储空间不足造成的保存失败按下面的登录提示或草稿备份流程处理。

## 登录信息保存失败

看到“浏览器无法保存登录信息”时，请检查浏览器是否允许本站保存数据，允许后直接重试登录。不要为了重试清空站点数据，已有未确认草稿仍留在原账号下。重新登录原账号并打开原文档后，仍需按提示确认恢复。

另一标签的编辑可能随旧登录暂停并返回登录提示；未确认输入仍按原账号保留。登录没有完整保存时，不会继续使用新账号令牌搭配旧账号名读取草稿。此提示不能通过反复刷新或改文档地址解决，应先允许站点保存登录信息。

## 工作台、小组、项目和模板

登录默认进入工作台，能查看“我创建的文档”“与我协作的文档”、近期更新和当前小组/个人项目/小组项目/私人模板数量，并进入文档、组织、模板、搜索、回收站和账号设置。手机顶部导航可以左右滑动；切换页面或调整窗口宽度时，当前入口保持可见，手动滑动后不会自动拉回。直接打开已授权的文档链接时，登录后仍回到该文档。各页面的“使用指南”留在当前页面，小组、项目和我的模板会先展开对应说明。

用键盘浏览公共导航页面时，第一个Tab会显示“跳到主要内容”；按Enter后可直接进入正文区域，再按Tab操作其中的按钮或输入框，Shift+Tab仍可回到页头工具。

工作台同时展示最多三条本人的待处理邀请，点击“查看并处理邀请”再明确接受或拒绝。返回工作台会重新读取；停留期间可“刷新概览”。组织卡片读取失败可以单独重试，不用空数字代表失败；归档小组/项目不计入当前概览。

账号资料、文档数量/近期更新和组织概览分别读取与重试。一处暂时加载失败，其他已经加载的资料仍可继续查看。需要读取最新文档时，在“近期更新”点击“刷新文档概览”；文档读取失败用“重试文档概览”，账号资料失败用“重试账号资料”，无需刷新整个页面。

### 邀请小组成员

在“我的小组”按名称或简介填写关键词，再点“查找小组”或按Enter。关键词、进行中/已归档分类和页码随网址保存，刷新可继续；切换分类保留关键词。没有匹配时可“清除小组筛选”。只筛选当前账号已加入的小组，上方收到的邀请仍单独展示，不搜索所有用户的小组。

从“我的小组”创建小组，再“查看成员”，按已注册用户名“发送邀请”。对方在自己的“收到的邀请”中接受后才加入。创建者可以分配管理员；创建者和管理员管理普通成员，普通成员可退出。创建者目前不能退出或转交小组，可归档并从“已归档”恢复。

邀请、小组列表和成员资料有各自的刷新或重试入口，一处读取失败不阻断另一处已加载资料。确认没有邀请时，上方显示简短状态条；“刷新邀请”可主动查看新邀请，等待或失败不会当作没有邀请。修改资料、邀请及成员变更等操作结果未确认时会暂停进一步变更，点击“核对操作结果”重新读取相关列表或成员关系。核对成功只说明读到了当前资料，请查看实际结果再决定是否重试，不要把其他列表的刷新或迟到旧回复当作写入确认。

创建小组显示结果未确认时，弹窗可“确认原小组”，或“稍后确认”后从页面上方“待确认的小组”继续。原名称、简介、创建标识和时间保存在当前浏览器的localStorage，按账号和后端服务隔离；关闭弹窗、整页刷新或重登原账号后仍可找回，不保存正文、密码或令牌。普通列表刷新不会确认或结束这些记录，列表暂时读取失败也可以确认原请求；不会按同名小组猜测成功。

确认始终使用原资料和同一标识。已创建的小组后来改名或归档，确认仍返回原编号及当前状态，不改回名称、不恢复归档；列表展示编号便于辨认。初次请求没有送达时，确认可完成该次创建。失败、取消、坏回复及身份变化保留记录；确认成功后再次主动创建才使用新标识，清理失败会明确提示已经创建。清除站点数据、换浏览器可能失去记录，同时在多个标签首次准备相同资料也不保证只发起一次创建，请先查看已有小组再决定是否重做。小组创建记录不会让其它写操作获得持久恢复保证。

小组只组织成员和资料分类。加入小组、成为管理员或收到项目链接都不会获得文档阅读或编辑权限；需原文档所有者另在“协作者管理”逐篇授权。退出或移出小组不会收回已有单篇文档权限；要收回时还需文档所有者另行处理。归档保留原成员与原文档，取消尚未接受的邀请；恢复小组不重新发送邀请。

### 用项目整理资料

在“我的项目”选择“创建个人项目”。小组项目总览先选择“选择小组创建项目”，进入具体小组的“查看小组项目”，由创建者/管理员点击“创建小组项目”；表单会默认当前小组，提交前仍请核对归属。打开“查看项目”，选择“加入已有文档”；个人项目可整理当前可读资料，小组项目只能主动加入你拥有的文档。

也可以在项目资料中点击“新建文档”：核对项目、填写标题，选择空白或内置模板并预览，再点击“新建并开始编辑”。文档与项目归类一起完成；新文档归你所有，小组普通成员也可在该组项目中创建自己的资料，其他人仍需逐篇授权。编辑页“返回项目”保留原入口；普通副本和模板中心创建不会自动加入项目。

创建回复暂未取得时，原项目、标题、起始模板和请求标识保存在当前浏览器；可以“稍后确认”，从项目页“待确认的新文档”继续。关闭、刷新或重登原账号后仍可找回；项目列表读取失败不妨碍确认。不要靠同名文档或列表刷新判断成功。确认只找回原创建，不重复建篇，也不重新加入后来移除的关联或恢复已删除正文；原项目归档/退组后仍可确认自己已完成的创建，打开文档仍按当前文档状态处理。切换账号隐藏原记录，记录不包含正文或登录凭据；清站点数据或换浏览器可能失去记录，请先核对已有文档。模板目录失败可先建空白文档或重试模板。

关联复用同一份正文、历史和链接，可同时加入多个项目。每位成员只看自己已被授权的文档标题、链接和数量，因此同一项目在不同账号下的可见文档数可能不同。“移出项目”只解除分类关联，“归档项目”保留关联并可恢复；两者都保留原文档和单篇权限。小组归档期间，其项目暂停访问。

项目内的文档标题关键词与页码随网址保留。打开文档后，左上角“返回项目”会回到原项目及其筛选位置，刷新编辑页后仍可返回；切换另一项目会重置文档筛选与页码。

### 选择和保存模板

模板中心有会议纪要、项目计划、学习笔记、工作周报、需求说明和项目复盘六个内置框架，支持用途分类、关键词筛选和预览。每次使用创建自己的独立文档与版本0，可以修改正文并邀请协作者。

手机预览中正文可独立滚动，关闭和创建按钮留在弹窗底部；先核对新文档标题，再创建。

复用已有内容时，先等修改保存，在编辑器“更多文档操作”选择“保存为个人模板”，或回“我的文档”选择“保存为模板”，填写名称、用途和说明。编辑器成功后留在原文档，可以继续编辑或“查看我的模板”；未连接、正在输入、上传或尚未保存完成时暂停首次保存，输入保留。在模板中心的“我的模板”预览并命名后创建新文档；工作台也提供“我的模板”直达入口。保存的是服务器处理时已保存正文，不包含本地未确认草稿。当前只读成员也可明确保存自己的副本，私人模板不带来源权限、历史或项目关联，来源未来变化、删除或撤权不会改变已保存的私人副本；图片仍依赖原地址。

每人最多100份、正文合计32 MiB、单份2 MiB。修改资料只改名称、用途和说明；要更新模板正文，可创建文档修改后保存为新模板。删除模板不可恢复，会释放对应逻辑正文配额，原文档和已创建文档保留。保存模板结果未确认时先核对“我的模板”，不会自动再次提交；关闭或刷新后不提供保存模板的原请求确认，请先核对已有模板再决定是否重新保存。创建文档可在当前标签按提示重试本次创建，同一模板和标题继续确认原请求，即使刷新或模板资料后来变化。确认成功后再次主动创建会生成新文档。

“重新读取模板”保留本次填写的新文档标题和资料草稿；读取失败时暂停保存，恢复后可以继续。若另一页面已修改模板，原输入仍可见但不能直接覆盖新资料，请先复制要保留的输入，再关闭重开按最新资料修改。未保存的模板资料只留在当前弹窗，关闭或刷新不会持久保留。

## 退出当前浏览器账号

工作台、账号设置、组织、模板、文档列表、搜索和回收站都提供“退出账号”。退出后同一浏览器的普通标签停止协作，原账号本地草稿保留；要继续处理，请重新登录原账号并明确选择恢复。其他设备仍使用各自登录，修改密码的全会话失效按账号设置说明执行。

看到“暂时无法退出”时，允许本站保存数据后点击“重试退出”，也可以“继续使用”。若已回登录页并提示账号名未能清除，当前浏览器登录令牌已经移除；允许保存数据后正常重新登录即可。不要为此清空站点数据，否则可能丢失原草稿。

## 查找自己和共享的文档

文档列表可切换“全部”“我创建”“与我协作”，标题筛选只作用于当前分类。分类、已提交的关键词和页码保留在地址中，刷新或浏览器后退仍可回到同一列表；改分类或关键词从第一页开始。

每篇文档显示“所有者”“可编辑”或“只读”。协作者管理和删除仅由所有者操作，编辑成员可改标题，只读成员可打开和创建自己的副本。列表加载失败可在原分类重试；“与我协作”为空时，请文档所有者按账号名添加你为协作者。

从工作台、文档列表、搜索、项目或模板打开文档，编辑页左上角会显示对应的返回入口，保留已提交的关键词、分类和页码。新建、导入及创建副本也可返回原入口；有未确认草稿时，“稍后处理”会返回原位置并保留草稿。直接打开分享链接时默认返回文档列表，分享地址不携带你的个人筛选条件，返回入口也不会授予文档或项目权限。

1. 用 testA 登录（开发演示密码 123456），新建文档。
2. 在列表或编辑器点击“协作者管理”，输入已注册的 testB，选择“可编辑”，点击添加。只读成员可以查看和搜索，不能改名或修改正文。
3. 用另一个浏览器、独立浏览器配置或隐私窗口登录 testB，再打开相同文档链接。普通标签页共享登录状态，不适合同时登录两个账号。

添加成员只修改当前文档权限，不发送通知。新用户先在登录页注册，再把用户名告知所有者；不需要直接修改数据库。

工具栏可点击“撤销/重做”，也支持Ctrl+Z撤销、Ctrl+Shift+Z或Windows Ctrl+Y重做；macOS使用对应Command快捷键。撤销仅针对当前标签自己的输入、删除及格式修改，模板加载和其他客户端的编辑不进入本标签撤销记录。没有可撤销/重做记录时按钮禁用，只读或同步未就绪时工具栏不可操作。断线自动重连保留当前页面的记录；刷新或重新打开页面会开始新的撤销记录，较早正文可从历史版本查看/恢复。

## 搜索和图片

选中文字后点击链接图标可添加链接，再次选中已有链接点击图标可移除；将光标放入链接后，可在预览中编辑或移除。输入www.example.com等常见域名会补成HTTPS，也可填写完整HTTP(S)、mailto邮箱或tel电话地址。非法/过长地址在弹层内提示，不保存到正文；Escape可取消，保存/移除可聚焦后用Enter或Space操作。粘贴内容中的无效链接会去掉链接属性并保留文本和其他支持的格式。

链接弹层打开期间，其他人输入或删除会同步移动原文字范围；若原文字已被完全删除，保存会提示重新选择，不把地址套用到邻近或新输入的文字。

从文档列表进入“搜索”，输入标题或正文关键词，按搜索按钮或 Enter。结果只包含当前有权查看的文档，并显示文档编号、所有者、当前权限与更新时间，方便辨认同名资料；点击标题可打开，超过 10 条可翻页。时间沿用服务器记录，不作浏览器时区换算。正文检索索引异步刷新，新输入可能稍晚出现；暂时不可用时页面显示中文错误并提供重试，保留关键词，不把读取失败显示为零篇。

摘要优先显示正文命中处；仅标题命中时显示正文开头，方便辨认内容。没有文字的资料会提示暂无文字摘要，图片不会转换为文字或图片地址。

刷新后若删除、撤权或内容变化使结果减少，会自动回到有效页，关键词保留；新搜索从第一页开始。最多可浏览前10000条结果，出现上限提示时请用更具体的关键词。权限仍以当前服务端判断为准，搜索结果不会授予编辑权限。

在已连接且可编辑的文档中点击图片按钮选择 JPEG、PNG、GIF 或 WebP，单张不超过 10 MiB。图片先上传，再以 Delta 同步并保存到正文；页面里的图片需能访问本机 MinIO 的 9000 端口。

也可以粘贴剪贴板中的图片文件或将图片文件拖到正文，一次最多10张。选中的文字在全部图片上传成功后才替换，失败时原文字保留；上传期间他人新增的文字不会被顺便删除。断线或变成只读时会取消在途上传，恢复后需重新选择文件；看到“正在上传图片”时先等待，再导出或恢复历史。

复制的网页或富文本若含内嵌PNG/JPEG/GIF/WebP图片，会先上传图片再插入整段内容，失败时原选区保留。私有blob、相对地址、SVG、损坏编码或超限图片以“图片无法粘贴，请使用上传图片”占位并提示，可随后用图片按钮补充；不会因此暂停整篇文档的协作。每段至多上传10张内嵌图，多出的图片保留占位。

网页的广色域颜色等不支持的颜色格式会去掉并提示，文字、粗体等其他格式保留；常规颜色仍保留。纯文本中的空字符会移除；过滤后完全为空时，不替换已选文字。

单次粘贴内容过大或格式过于复杂时，会提示分段粘贴并保留原选区，不会暂停编辑或先上传图片；可减少本次内容后重试。

## 文档内查找与替换

在文档中点击“文档内查找”或按Ctrl/⌘+F。输入本文文字后显示匹配数量，按上一处/下一处或Enter/Shift+Enter导航，当前匹配高亮；可勾选“区分大小写”。这是本文文字的字面查找，不是跨文档搜索或正则表达式，不查询图片地址，也不跨图片拼接文字。Escape或关闭按钮返回正文。

滚动编辑时，连接与保存状态会留在页头下方，方便随时核对。查找面板会避开状态栏；手机低高度窗口中可滚动面板访问其余操作，关闭后重新打开会保留关键词并重新显示当前匹配。

有编辑权限且已同步时，可填写“替换为”，替换当前或全部匹配；留空删除匹配文字，相同文字不会产生编辑。全部替换只处理执行时的原匹配，不递归替换新插入的内容。新文字保留匹配首字符的行内格式，原图片和未匹配内容保留；可从工具栏或正文撤销/重做此次替换。

只读可以查找，不能替换；断线、输入/上传未完成或尚未保存时先等待。仍需查看页面保存状态，确认修改已保存。查找最多200字符，替换输入最多10000字符；正文2 MiB、单次修改4 MiB和10000操作片段限制继续生效，超限时不修改正文，请缩小范围或替换文字。远端编辑会更新匹配位置；关闭/离开页面后高亮不会残留。

## 断线、草稿与数据保留

出现“旧草稿无法自动恢复，原始记录已保留”时，旧记录仍在浏览器中。已成功加载的编辑区显示服务器保存正文；文档打开失败时没有取得服务器正文，页面会明确说明。先点击“保存原始草稿”留存副本，新编辑会单独保存，不自动覆盖旧记录。正常可恢复草稿仍走确认恢复流程。原始记录文件用于留存和后续排查，不是CoPage文档副本，不能直接导入；无法保证损坏内容完整自动重建。下载失败时可重试，原记录不会因此删除；不要清空站点数据。

“发现未确认的本地编辑”弹窗提供“下载富文本草稿”“下载纯文本草稿”和“稍后处理”。稍后处理返回列表，草稿仍留在当前浏览器；重新打开还会询问。只读时不能同步草稿，可先下载，获得编辑权限后重新打开或重试，再明确恢复。即使访问权限已移除、文档已删除或读取失败，原账号仍能从失败页面保存此浏览器已有的本地草稿；这不会恢复服务器访问权限、取得服务器正文或提交原操作。换账号不会显示对方的草稿入口。

下载是完整正文副本，不等于原未确认操作得到确认。富文本文件保留格式和图片地址，可从列表导入为独立文档，不复制图片文件、成员或历史；超过正文2 MiB、文件3 MiB或10000片段时仍完整下载，需分段整理再导入。确认浏览器下载完成后再清理数据；下载失败可重试，不会清除原草稿。

文档首次打开失败时，页面显示“重试加载”，网络/服务恢复后可直接重试，不必清除浏览器数据。加载失败或尚未读完时返回列表、刷新，都保留原有草稿；重新读取成功后仍先按提示确认恢复。地址无效时请返回列表重新打开；确实不存在或无权限的文档不能靠重试获得访问权限。

断线期间编辑区暂时只读；后端恢复后自动重连并继续编辑。未确认的修改保存在当前浏览器，刷新/重开后先确认恢复或丢弃。历史超过 2000 条时分批追赶，每批最多 256 条；只要所需历史仍在保留范围内，可以自动合并未确认编辑。所需版本已清理、日志缺失或恢复失败时保留本地内容并转只读，请先复制备份。降权时也不会自动丢弃未确认草稿。

持久文档在 MySQL 数据卷，图片在 MinIO 数据卷；Redis 和 ES 可以从持久数据重建。不删除 Docker 数据卷；备份/恢复流程与已验证范围见[后端服务器部署说明](后端服务器部署.md)。草稿不在服务器备份中，清除浏览器站点数据会失去本地草稿。

浏览器空间不足或拒绝保存草稿时，编辑器会提示先复制内容。若此时返回列表、登录失效或其它标签退出使编辑器离开，会显示“请先备份未确认内容”：下载富文本或纯文本副本，或复制下方完整文字。复制被浏览器拒绝时，点击文字框可全选后手动复制。确认文件确实下载完成后，再点击“已备份，继续登录”。

此页仅暂存内存副本，刷新或关闭会失去它，离开提醒不能代替保存。富文本备份保留当前完整正文、格式和图片地址，不包含账号凭据、图片文件、成员或历史；重新登录后从列表导入为独立新文档，不会自动补交原文档操作。超过导入的正文2 MiB、文件3 MiB或10000片段上限时仍可完整下载，但需先分段整理才能导入，不会悄悄截断正文。换账号不会替换已经显示的原账号副本。

保留验收文档 26 及其 testB 编辑权限；它不是临时清理对象。当前阶段不启用 AI 问答，公网部署可选。

## 历史版本

在编辑器点击“历史版本”，可分页查看版本并预览富文本。所有者可以填写名称保存重要版本、取消标记或恢复正文；普通协作者只能查看。恢复需要先等待当前编辑保存和图片上传完成，再确认操作。恢复会生成一个新版本并实时同步；若其他成员已有新编辑，系统拒绝覆盖，需刷新列表后重新核对。

恢复结果未确认时，请点击“确认原恢复”，继续确认原来的目标和请求；刷新列表、查看其他版本或关闭历史窗口后再打开，都不会改成新的恢复。确认原结果不重复生成版本，也不覆盖恢复之后的新编辑。等待期间可继续预览和管理重要版本，但暂不发起新恢复或清理历史；确认失败仍保留等待。原UUID、目标版本和预期版本保存在当前浏览器，按账号、服务和文档隔离，不保存正文或凭据；整页刷新、关闭标签或重新登录原账号后，打开本篇“历史版本”可继续确认，不会自动重发。切换账号隐藏原等待。清除站点数据、退出无痕窗口或换浏览器可能失去记录，此后应先核对当前正文。

需继续其他操作时可以明确“结束等待”，原恢复仍可能已经生效，此操作不撤销或确认原恢复；先查看当前正文再决定是否重做。浏览器不允许可靠读取/保存原记录时会停止发送替代请求，请恢复本站存储并使用当前版本浏览器，再重开历史。服务端已确认但本地记录清理失败，会同时显示已确认结果和记录未结束的提示；再次确认沿用原UUID，不重复生成版本。同一站点多个标签的准备与清理协调执行，已有原等待时只展示原确认入口。手机上的历史窗口会限制在屏幕宽度内。

普通历史由增量日志与周期快照还原，不为每次键入复制整篇正文。默认清理策略为最近 30 天、最多 10000 次操作、64 MiB 逻辑内容，先达到的限制生效；**自动清理默认关闭**。所有者可在历史抽屉查看范围并点击“清理过期历史”，确认后才清理。重要版本独立保留，每篇最多 20 个、总正文 32 MiB；当前正文和重要版本不随普通历史清理丢失。文档 26 排除在手动和自动清理之外。

被清理的普通版本不能恢复，超出保留范围的离线草稿不能自动合并。策略配置、启用方法与容量边界见[历史版本与保留策略](历史版本与保留策略.md)。

## 从模板新建

在“我的文档”点击“从模板新建”，选择会议纪要、项目计划或学习笔记，先预览内容、填写标题，再点击“创建文档”。新文档归当前账号所有，成员需另行添加，修改不会影响模板或其他文档。模板正文作为版本 0 保存，之后可从历史版本恢复。仍可直接新建空白文档。

## 复用已有文档

在列表或编辑器点击“创建副本”。可以填写新标题；留空使用原标题加“的副本”。确认后打开自己拥有的新文档，正文来自复制操作时服务端已保存的完整版本，保留格式和图片地址。

只读成员也可创建自己的副本。新文档没有原协作者、父级或历史，从版本0开始保留初始正文；以后修改或恢复副本不会影响原稿。来源撤权或删除后不能再复制，但自己已创建的副本仍可使用。图片沿用原地址，不复制图片文件，地址失效时需重新上传。

编辑器中尚在输入、上传、保存、重连或等待草稿恢复时先完成这些步骤；副本不包含未确认本地草稿。结果未确认时可在弹窗“确认原副本”，或到“我的文档”的“待确认的副本”继续确认原请求而不重复生成；同标签刷新或重登原账号后仍可找回，确认成功后再次主动创建才会生成新文档。关闭标签或清站点数据可能失去本次记录，此后应先核对列表；原目标已删除时从回收站恢复，不生成替代文档。站内复制保留服务器已有完整正文，不经过文件转换；原正文2 MiB限制仍保持。

## 打印和另存为 PDF

在已授权的文档中点击“打印 / PDF”或按Ctrl/⌘+P，等待预览和图片加载完成。预览显示服务端已保存的固定版本；其他成员继续编辑时不会悄悄改变它，需要最新内容请点“刷新预览”。已授权的只读成员也可打印，断线、同步/输入/上传/保存未完成或仍待选择恢复草稿时先等待。

点击“打开打印窗口”，可选择打印机或浏览器“另存为 PDF”；纸张、边距和页眉页脚按浏览器设置。正文保留支持的富文本和已加载图片，隐藏编辑器控件、远端光标与查找高亮。关闭或取消打印不会修改文档。

图片未加载成功时先刷新重试；默认不能打印，明确勾选“我接受缺图，仅打印当前可见内容”后才继续，副本会注明可能缺图。撤销访问权限后预览关闭；打印按钮会再次校验服务器权限。PDF用于阅读，不包含权限、历史和本地草稿，也不能作为CoPage富文本副本重新导入或替代数据库/图片备份。

## 导入和导出

在“我的文档”点击“导入文档”，选择 UTF-8 .txt 文件或 CoPage 导出的 .json 副本，核对标题后确认。文件最多3 MiB，解析后的正文最多2 MiB和10000个片段；格式、JSON转义和换行也占正文容量，文件本身较小仍可能因正文容量被拒绝。文本换行统一处理，HTML标签作为普通文字，不解析为网页。导入创建归当前账号所有的新文档和历史版本0，不覆盖原文档，不复制来源成员或历史。无效编码、编辑操作、未知格式和不安全链接会被拒绝，错误显示在窗口中。

若显示“原导入待确认”，窗口保留原文件和实际提交标题，点击“确认原导入”确认或完成同一次请求，不使用后来修改的内容新建。也可“核对我的文档”查看本人文档和原标题筛选，但列表存在或为空都不会自动确认结果。关闭窗口或刷新后，需重选同名、同字节文件并填写相同标题，才能沿用当前标签中的原标识；文件内容不持久保存。关闭整个标签、清站点数据或换浏览器可能失去原标识，此时先核对已有资料再决定是否重做。

在编辑器点击“导出文档”，选择 CoPage 富文本副本（.json）或纯文本（.txt），点击“下载副本”。已授权的只读成员也可下载；未确认编辑、同步、图片上传或草稿恢复选择尚未完成时需等待。副本来自服务端一个已保存版本，生成后提示版本号；其他成员同时编辑时可能有更晚版本，副本不会阻止他们编辑。

生成文件前会再核对访问权限。期间撤权或连接状态变化时取消生成并显示提示；离开编辑页会取消在途导出，返回后需重新发起下载。

CoPage副本可再次导入并保留支持的富文本格式，纯文本便于阅读但不保留格式，图片显示为地址。导出文件最多3 MiB，可完整保存当前2 MiB正文并保留封装空间；已有正文超过10000片段仍完整下载，重新导入须先分段整理，不会为满足导入上限而截断。图片只保留原地址，不打包图片文件，旧地址失效或换环境后需自行迁移图片。副本不包含账号、成员权限、历史版本或本地草稿，不能替代数据库与图片卷备份。暂不支持Word、Markdown或HTML格式转换。PDF通过浏览器打印入口生成，用于阅读。

## 回收站与误删恢复

在“我的文档”删除文档后，它进入所有者的回收站，原协作者立即停止访问。从顶部“回收站”进入，按标题及文档编号核对目标，再点击“恢复文档”。同名时可与原文档地址中的编号比对，确认框也会注明编号；核对原协作者会恢复原权限的提示后确认。成功后可直接“打开恢复的文档”，编辑页可返回原回收站页码；也可回到文档列表。只读或可编辑协作者都不能查看他人的回收站或恢复文档。

资料较多时可按文档标题查找，最多200字符，只匹配本人已删除文档的标题，不搜索正文；输入`%`或`_`按普通字符查找。提交查找后从第一页开始，翻页、刷新及打开恢复文档后返回都保留已提交的关键词；“清除查找”回到完整回收站。没有匹配结果与整个回收站为空会分别说明，读取失败不会显示为零篇。

删除或恢复显示“结果未确认”时，先点击对应的“核对删除结果”或“核对恢复结果”，读取原文档的当前状态，再决定后续操作。列表刷新、改变筛选或空列表不能证明某次写入完成，也不会解除待核对提示。暂时无法核对时保留目标，稍后重试核对；浏览器无法读取当前身份时，恢复本站存储后也可继续核对。离开只取消等待，不撤销服务器已经完成的变更。状态提示表示核对当时的事实，其它标签后续操作仍可能改变状态。

恢复保留当前正文、版本号、尚存的历史与重要版本，不会倒退版本号；已经清理的普通历史不会重建。重复恢复请求不覆盖恢复后产生的新编辑。当前没有永久删除或自动清空入口，既有软删除文档仍保留。列表与回收站每页 20 篇，删除/恢复最后一页最后一篇时自动回退；加载失败显示错误，可点击重试。

## 注册与登录提示

登录表单默认不填写密码。首次使用可点击“没有账号？注册”，输入 3～50 字符用户名、可选昵称、6～64 字符密码和一致的确认密码。密码 UTF-8 长度不超过 72 字节，中文等多字节字符更早达到限制。注册成功后密码清空，再登录；本地开发可显式点击“填入演示账号”，生产构建不展示演示信息。

用户名和昵称支持中文及其他Unicode；粘贴的名称若包含内部换行、制表或其他控制字符，会明确拒绝，请删除这些字符后再提交。首尾空白按既有规则处理，可选昵称留空时使用用户名；不会改写既有账号。

从文档、搜索或模板链接进入时，登录后返回原页面。业务请求遇到失效 token 会转到登录并明确提示；错误密码显示在表单内，不当作整个站点退出。重新登录不会自动删除本地未确认草稿，打开原文档后仍按草稿确认流程处理。登录回跳只允许本站支持的内部页面。

同一浏览器的普通标签页共享登录状态。在其中一页退出或重新登录时，其它页面会关闭旧协同连接、暂停编辑并返回登录提示，原账号的未确认草稿仍保留。换成其它账号不会恢复旧账号草稿；重新登录原账号回到原文档后，仍先确认是否恢复。登录页面离开或收到其它页面的会话变更时会取消在途登录请求，迟到响应不会重新写入旧账号。普通退出的页面同步只覆盖共享浏览器存储；“修改密码”另由服务器凭据版本使所有旧登录失效。

## 登录过期与断线

如果登录页同时提示“未能完整清除失效的登录信息”，服务端已经拒绝旧登录，但浏览器未完成清理。请允许本站保存数据后正常重新登录；不要清空站点或删除原草稿。使用原账号回到原文档，再明确选择恢复草稿。临时网络故障不会按此流程当作登录失效。

正文读取及草稿选择完成前，浏览器重新联网仍保持等待，不会跳过恢复/丢弃选择。离线时点击恢复会保留草稿并等待联网，再正常同步；已经开始的协作可继续自动重连。

临时断网或后端重启时，编辑器停止输入并自动重连；有效登录不会因此退出。服务端确认登录过期时会进入登录页并说明草稿保留。重新登录返回原文档，发现未确认草稿时先选择“恢复草稿并同步”，不会未经确认自动重放；不要为解除提示清空浏览器存储。

## 编辑页工具与手机阅读

顶部保留查找、分享和“更多”。“更多”按权限提供重命名、历史版本、创建副本、导出、打印及使用指南；只有文档所有者可管理协作者。标题省略时点击标题可查看全文，键盘Enter打开、Escape关闭。窄屏格式工具分行显示，保存状态始终单独可见；“已连接”和“所有修改已保存”表示不同状态。左上角仍返回原入口并保留已提交筛选。

## 工作台本地草稿入口

打开文档时若发现另一标签仍在处理的本地草稿，本页会明确说明未接管；本页的“所有修改已保存”仅表示本页编辑。请回原标签或工作台的本地草稿核对。关闭说明只隐藏提示，不删除草稿，也不提交原操作；原记录消失后说明会自动消退，但记录消失本身不等于已经同步。原标签离开后，重新打开文档仍须明确选择是否恢复。

从工作台“查看本地草稿”打开此浏览器、当前登录账号的记录。旧草稿没有保存文档标题，因此清单按文档编号和本地保存时间识别；时间无法确认时显示未知。可以分别下载完整富文本或纯文本副本，也可以“继续处理此文档”回到原编辑页按恢复提示处理。多标签可能留下多份记录，入口不自动接管、提交或删除草稿；记录消失不代表已经同步。

撤权、删除或服务端读取失败时，仍可从已加载的工作台下载本地副本；恢复原访问权限须由文档所有者处理。工作台本身尚未加载而完全离线时，本站页面不保证可用。损坏记录可保存原始记录副本留存，但不能直接导入文档；编号无效时不提供跳转。读取失败会明确提示，不能当作没有草稿。切换账号或登录信息不可读时隐藏旧清单，恢复本站存储后关闭重开；需要处理原账号记录时重新登录原账号。浏览器或站点数据清除后无法靠此入口找回，入口不提供跨设备草稿同步。

## 中文等组合输入

组合输入期间显示“正在输入”，远端正文在本次输入结束后合并，避免尚未确认的文字被覆盖。连接中断或权限变为只读时，尚未确认输入保存在本地草稿中；不要清空浏览器存储。恢复连接与编辑权限后，按页面提示选择“恢复草稿并同步”。

## 正文容量

当前整篇富文本正文最多 2 MiB，单次修改最多 4 MiB，按 UTF-8 序列化内容计算，文字和格式属性都占容量；图片文件另行上传，正文只保存地址。粘贴会先检查替换后的完整正文，超限时保留原正文和选区，请缩小内容或另建文档。图片上传完成后会再核对最新正文容量。导入正文仍受同一2 MiB边界限制，导入/导出文件封装最多3 MiB。

普通键入、格式修改及撤销/重做也会检查容量，超限时提示并退回本次修改，保留既有正文和历史操作，仍可删除或缩减内容。另一人编辑后导致本次撤销超限时，释放容量后可再次撤销。服务端以最终合并正文校验；收到明确拒绝且显示本地草稿保留时，按草稿提示处理。

## 连接无响应

即使浏览器仍在线，连接也可能收不到服务端响应。客户端每20秒发心跳，等待回复超过15秒后暂停编辑、保留草稿并自动重连；后台标签页节流可能延长检测时间。恢复后按页面提示处理尚未确认草稿，不要清空浏览器存储。正常组合输入不会阻止心跳回复处理。

## Docker Desktop运行时端点启动失败

2026-10-07实遇Docker Desktop启动失败，日志包含初始化Inference manager、dockerInference与“The file cannot be accessed by the system”。这属于Docker自身启动阶段，CoPage数据库和正文尚未加载；[Docker仓库同类问题](https://github.com/docker/desktop-feedback/issues/554)描述了残留Windows套接字不可删除的情况。不能因为这个报错选择恢复出厂或删除数据卷。

本次通过官方命令退出Docker，并确认没有Desktop/backend进程；核对精确的 %LOCALAPPDATA%/Docker/run 与 %LOCALAPPDATA%/docker-secrets-engine 只含零字节运行时套接字，再把两个目录分别改为带唯一stale后缀的同级备份，保留原对象。正常启动后Docker重新创建端点，原MySQL/Redis/RabbitMQ/ES/MinIO与项目数据继续使用；没有修改AI设置、权限、Windows/WSL配置或安装升级。故障目录备份暂保留。

这是本机已验证的针对性处理，不是local.ps1自动执行的行为。再次遇到时先看最新日志、确认Docker已退出及目录内容；目录含其他数据、仍有进程或报错不同则不要照搬，更不要改动Docker/wsl、磁盘镜像、容器和数据卷。引擎就绪后用原start入口恢复CoPage；status须重新检查，不沿用旧PID。

## 账号设置

从“我的文档”顶部进入“账号设置”，可更改昵称、查看不可修改的登录用户名。昵称1～50字符；保存后重新打开文档，新连接使用新昵称。

修改密码时输入原密码、新密码和一致的确认密码。新密码6～64字符、UTF-8最多72字节，不能是纯空白或与原密码相同。原密码输入错误会在当前页面提示，登录仍保留；成功后所有旧登录失效，需用新密码重新登录。文档、成员权限和本地未确认草稿不删除，返回原文档后先确认是否恢复。普通退出与改密的失效范围不同。

服务器已经完成的保存不因关闭页面或取消请求而撤销。若改密请求结果未确认，先尝试新密码登录，无效再试原密码；不要丢弃已有草稿。当前不提供邮箱找回、用户名变更或第三方登录，需要原密码才能自助改密。
## 创建结果未确认时

空白新建、模板和导入正在等待回复时，离开页面或在其它标签切换账号会取消当前等待，迟到回复不会把你拉回旧文档。取消不撤销服务器已经完成的创建。

如果看到“创建/导入结果未确认”，可在当前标签重试原内容，也可先核对我的文档。刷新后重新选择相同文件名、相同字节和标题，仍继续确认原导入；空白、内置模板、私人模板和副本也保留本次重试。修改文件、标题或来源会成为新的创建，请先核对原结果。关闭标签或清站点数据可能失去记录，此后先检查列表；已经移入回收站的原目标仍需恢复，不重新生成。

收到的回复若缺少有效文档编号，也会按“结果未确认”保留原创建标识，不当作已经确认。按相同内容重试即可继续确认原请求；不要为了重试而清空站点数据。

登录失效时保留本次创建标识；在当前标签重新登录原账号，再重试相同内容，仍确认原文档。模板弹窗关闭后，页面的“重试本次创建”继续原模板和标题，不需要重新打开预览，也不会偷偷改成另一个模板或新版本。

正常确认后自动打开文档，再次主动创建会生成新篇；明确400拒绝可修正后提交。浏览器无法保存重试记录时不会发送创建，请允许本站保存数据后重试，不要清空已有草稿。创建已成功但记录未能结束时会明确提示，先恢复存储再创建；不会自动重试或因回复丢失删除文档。
成员列表未成功加载或正在刷新时，添加、切换权限和移除暂不可用；加载失败后点击“刷新列表”。若成员更新结果未确认，先刷新核对真实权限，再决定是否重试。不存在用户名等明确输入错误可直接修正。文档删除或失去管理权限会关闭编辑器里的成员弹窗，迟到回复不会重开它；取消等待不回滚已经完成的成员更改。
登录到期后，服务器会在请求、协同消息或心跳中停止旧登录，页面提示重新登录；未确认草稿仍保留。正常登录后回到原文档，先核对并确认恢复，再继续编辑。默认登录期限24小时，服务器可通过JWT_EXPIRE_HOURS配置；本轮没有缩短正常登录期限。

开发验收可使用 `node scripts/production-compose-check.mjs --session-expiry-smoke`，在随机隔离生产项目中验证过期会话的写入/广播/握手拒绝及有效成员接力，并自动清理该项目。`session-expiry-smoke.mjs` 的浏览器辅助模式仅供本轮合成账号验收，需显式测试密钥及参数，绑定回环地址和随机路径，结束后关闭；它不是应用功能或生产认证接口，不应作为常驻服务运行。
