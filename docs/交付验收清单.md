## 3. 人工浏览器演示（由演示者最终确认）

1. 启动前端 `npm --prefix frontend run dev`，在 `http://localhost:5173` 登录、新建文档；另开标签页访问同一文档。两页都显示“已连接”后轮流输入，检查文字和 revision 收敛。不同账号参与前，应先确认其协作者权限；知道链接不等于有编辑权。
2. 刷新一页，确认正文仍在；使用只读协作者或无权限账号分别检查不能编辑、不能访问。演示错误账号登录与无 token 请求被拒绝。
3. 在**事先确认可中断的本地测试实例**上演示断线：停止其中一个后端时，连接到该实例的页面应显示重连并暂时只读；恢复同一实例后应重新同步并可继续编辑。不要在有他人使用的服务上执行此步骤。
4. 若出现未确认草稿，刷新/重开后应先显示恢复确认，而非自动重发；确认前后分别检查服务端版本，防止重复提交。超过 2000 条且历史仍在保留范围内时分批追赶；所需历史已清理或有缺口时保留本地内容并转只读，需要先复制备份。
5. 从所有者的“协作者管理”添加已注册成员、切换只读/编辑权限并移除；已打开的另一端应实时改变编辑状态，撤权后暂停且不能搜索或重新访问该文档。在两端预先连接的情况下通过图片按钮选图，检查上传、另一端实时显示和刷新保留。搜索标题/正文，检查高亮、分页、空结果和错误重试。上述入口已于 2026-10-03 联合验收通过；远端彩色光标与名字标签的完整断线/失焦范围承接 2026-09-30 记录。
