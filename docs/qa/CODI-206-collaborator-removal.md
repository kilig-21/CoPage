# CODI-206 移除协作者确认复验

隔离预览中准备两个同昵称、账号各 50 字符的成员。Chrome 1280×850 和 320×640 改前都显示两个同名「移除」按钮。打开确认后连按 Tab 六次没有进入确认操作，Esc 关闭整个管理面板，明确取消后落焦到页面主体。320px 的确认区域横跨整个视口，账号末尾不可见。

| 场景 | 最终结果 | 证据 |
| --- | --- | --- |
| 核对身份 | 操作名称含账号，管理弹窗切换到确认视图，展示完整账号、昵称、当前角色及撤权后果。320px 确认区 x=12–308，原账号完整折为两行。 | [桌面改前](assets/codi206/before-1280.png) · [桌面改后](assets/codi206/after-1280.png) · [窄屏改前](assets/codi206/before-320.png) · [窄屏改后](assets/codi206/after-320.png) |
| 键盘取消 | 默认聚焦取消，Tab 到「移除权限」。Esc 或激活取消均回对应原行和列表滚动位置，未发出 DELETE。 | [窄屏取消](assets/codi206/cancelled-320.png) |
| 正常提交 | 实际 DELETE 挂起时保留目标与加载提示，取消禁用。仅发出一次针对所选用户编号的 DELETE。独立身份再次打开时只该账号获 403，另一人权限、原正文和修订号一致。 | [窄屏请求中](assets/codi206/pending-320.png) · [窄屏名单复核](assets/codi206/completed-320.png) |
| 响应未知 | 实际提交后将浏览器回复替换为 HTTP 503，界面要求刷新名单核对。刷新后真实服务与另一浏览器身份均表明只移除了所选账号。 | [窄屏待核对](assets/codi206/unknown-320.png) · [窄屏核对后](assets/codi206/verified-320.png) |

两档分别验证正常和响应丢失；移除只操作本轮合成文档和账号。实体触屏、读屏器、其他浏览器未覆盖。
