# CODI-207 共享文档失败与恢复复验

在隔离预览中用 Chrome 1280×850 和 320×640 打开真实的未授权文档。改前的提示要求核对账号，界面上没有账号名称。空编辑区高 600px，在两档视口分别占可见高度 600px 和 368px。

| 场景 | 最终结果 | 证据 |
| --- | --- | --- |
| 未获授权 | 真实 403 显示当前登录账号和授权指引，空编辑区退出视口与可访问树。50 字符账号在 320px 完整折为两行，页面无横向滚动，重试按钮高 44px。 | [桌面改前](assets/codi207/before-1280.png) · [桌面改后](assets/codi207/after-1280.png) · [窄屏改前](assets/codi207/before-320.png) · [窄屏改后](assets/codi207/after-320.png) |
| 补授只读权限 | 文档所有者在真实服务授予只读权限。接收者从原地址按 Enter 重试，等待期间没有空编辑区，随后看到原正文，编辑器标记只读并完成同步。 | [窄屏恢复](assets/codi207/recovered-320.png) |
| 真实 404 与临时故障 | 未知文档编号显示链接核对提示。浏览器拦截一次请求返回 503 时显示服务暂不可用；键盘重试恢复真实服务与只读正文。两种提示均不显示账号。 | [窄屏 404](assets/codi207/404-320.png) · [窄屏 503](assets/codi207/503-320.png) |
| 失败时保留草稿出口 | 实际编辑后拦住 WebSocket 提交，断开连接并关闭标签。重新打开时模拟读取 503，仍能用键盘下载纯文本草稿，核对文件含未同步文字。 | [窄屏草稿下载](assets/codi207/draft-320.png) |

实际验证范围为两个 Chrome 窗口尺寸及键盘流程。未覆盖实体触屏、读屏器和其他浏览器。
