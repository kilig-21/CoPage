# CODI-228 编辑器在线名单

在本地隔离环境中让三个合成账号通过真实协作连接进入同一文档，使用 Chrome 低动效模式。改前「+1」没有键盘入口，实际悬停只露出第三位的首字「采」。改后头像与人数折叠成一个入口。按 Tab 到入口、Enter 展开，屏幕内可读三位完整昵称；继续 Tab 可进入名单，Escape 关闭并回到入口。

| 视口 | 状态栏高度改前 → 改后 | 正文画布顶部改前 → 改后 | 展开可见 |
| --- | --- | --- | --- |
| 1280×850 | 41 → 41px | y=148 → 148px | 3 位完整昵称 |
| 320×480 | 41 → 41px | y=126 → 126px | 3 位完整昵称 |

- 短窄屏 [改前悬停](assets/codi228/before-320.png) · [改后打开](assets/codi228/after-320.png) · [收起](assets/codi228/closed-320.png)

模拟触控可点击入口打开名单，点击正文露出的区域关闭并继续编辑。真实浏览器中另外两位陆续离开时，展开的名单实时从三位更新到一位。断线时收起，重连后重新显示单人入口。重连后继续输入并收到保存确认。

生产构建 Chrome 5 项通过，覆盖真实三人在线、键盘、短屏、读写授权及离线恢复。前端 482 项测试、lint、Vite 构建通过。触控使用 Chrome 模拟，未覆盖物理触屏、读屏器和其他浏览器。
