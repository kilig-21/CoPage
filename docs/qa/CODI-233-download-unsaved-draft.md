# CODI-233 本地草稿写入失败时下载富文本

在隔离 Chrome 打开合成文档。暂缓第一条协作写操作，仅对本地草稿存储键注入 `QuotaExceededError`。等待页面反馈后继续输入带粗体的文字，再按 Enter 下载副本。

| 视口 | 改前 | 改后 |
| --- | --- | --- |
| 1280×850 | 只提示手动复制 | 状态栏标明本地失败，可下载当前富文本 |
| 320×480 | 只提示手动复制 | 下载入口完整可见，正文仍可读 |

两档下载文件均包含告警出现后输入的粗体。下载后原文档服务端版本仍为 0；恢复真实连接后原文档保存到版本 2。恢复浏览器草稿写入与服务端确认分别验证，失效的下载提示都会收起。两档再次制造未同步修改后离开，现有临时备份页仍保留最后输入。
