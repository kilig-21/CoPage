# CODI-209 实时权限变化与草稿备份复验

隔离服务使用两名合成账号。协作者真实编辑后仅拦住发送到服务端的未确认写入。文档所有者用真实权限请求将其改为只读或移除，再核对同一标签的状态。改前提示建议备份后重开，编辑器里没有可下载的备份操作。320px 位于文末时，详细提示不在视口内。

| 场景 | 最终结果 | 证据 |
| --- | --- | --- |
| 改为只读 | Chrome 1280×850 和 320×640 保存状态旁显示「备份草稿」，按钮高 44px。320px 从原文末位置测得按钮顶部 y≈74，横向滚动宽度仍为 320px。 | [桌面改前](assets/codi209/before-1-1280.png) · [桌面改后](assets/codi209/after-1-1280.png) · [窄屏改前](assets/codi209/before-1-320.png) · [窄屏改后](assets/codi209/after-1-320.png) |
| 失去访问权限 | 两档均保留当前页的备份入口，键盘可下载纯文本和富文本文件。读取真实下载文件包含未同步文字，读取服务端正文则无该文字。Esc 回到原按钮。 | [窄屏改前](assets/codi209/before-0-320.png) · [窄屏入口](assets/codi209/after-0-320.png) · [窄屏下载](assets/codi209/download-0-320.png) |
| 上下文与空态 | 返回文档列表后入口消失。另一标签退出原会话，当前标签退回登录；换另一合成账号后只看到该账号的权限提示，原备份入口与弹窗都不显示。已确认所有编辑的文档降为只读时没有备份入口。 | 浏览器断言 |

下载内容为原账号在该标签已经拥有的本地正文副本。未覆盖实体触屏、读屏器和其他浏览器。
