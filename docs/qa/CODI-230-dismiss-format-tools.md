# CODI-230 窄屏格式化后继续写作

在隔离 Chrome 的 320×480 视口打开合成的暑期校刊。选中第 27 段的「校稿。」，用键盘展开格式工具、应用粗体，再按 Escape。

| 指标 | 改前按 Escape 后 | 改后按 Escape 后 |
| --- | --- | --- |
| 展开的格式项高度 | 153px | 0px，保留折叠入口 |
| 滚动位置 | y=1604px | y=1451px，等于展开前 |
| 正文焦点与已应用的格式 | 正文，粗体保留 | 正文，粗体与原选区保留 |

收起后完整选区仍在视口内，可直接继续编辑。展开时按钮明确显示「收起格式工具」。如果焦点在即将隐藏的工具，收起后回到入口。段落样式选项展开时先关闭内层菜单。模拟输入法合成期间的 Escape 保留工具状态。
