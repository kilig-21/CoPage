# CODI-213 打印图片就绪复验

在隔离本地库使用同一份合成正文、同规格 64×64 棋盘格及 Chrome 158。成功场景实际读取 CoPage 私有图。失败场景只拦截预览图片请求，编辑器和文档读取仍走真实后端。计时从打开打印预览到可打印或看到缺图。

| 视口和请求 | 改前 | 改后 |
| --- | --- | --- |
| 1280×850，HTTP 200 | 10.199 秒，图片已解码但误报缺图 | 0.115 秒，可直接打印 |
| 320×640，HTTP 200 | 10.203 秒，图片已解码但误报缺图 | 0.140 秒，可直接打印 |
| 1280×850，注入 HTTP 503 | 10.178 秒后才提示缺图 | 0.121 秒显示提示 |
| 320×640，注入 HTTP 503 | 10.286 秒后才提示缺图 | 0.126 秒显示提示 |

改前在两个窗口中均观察到监听器绑定于第一个图片节点，浏览器在被替换后的第二个节点触发加载或失败。改后在预览容器捕获事件并读取当前图片，于响应后 5–15ms 更新就绪反馈。计时包含收到图片响应后的界面更新。

- [桌面改前](assets/codi213/before-200-1280.png) · [桌面改后](assets/codi213/after-200-1280.png) · [窄屏改前](assets/codi213/before-200-320.png) · [窄屏改后](assets/codi213/after-200-320.png) · [窄屏缺图](assets/codi213/after-503-320.png)
- 浏览器回归固定复现请求等待期间替换节点，断言实际解码后四秒内可打印。再刷新模拟 503，通过键盘确认缺图后可打印，再刷新真实图片可直接打印。两档均覆盖。
- 模拟返回 HTTP 200 和不可解码的 PNG，Chrome 在桌面约 0.117 秒、窄屏约 0.125 秒显示缺图并需要确认。
- 在 320px 保持图片请求真正未完成，打印保持禁用，约 10.05 秒后走缺图兜底并显示确认操作。
- 同一隔离库重跑 CODI-212 的加载、空态、权限 503 与真实撤权，保留打印前权限校验、版本快照以及 Chrome A4 PDF 输出。

Chrome 对生产构建的单后端浏览器回归 28 项全部通过。前端 482 项测试、lint 和 Vite 构建通过。跨副本用例、实体打印机、系统打印对话框和其他浏览器不在本轮验证中。
