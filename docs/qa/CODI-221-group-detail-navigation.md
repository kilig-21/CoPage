# CODI-221 查看小组成员时保留列表

在本机隔离环境用 Chrome 和合成小组复现。打开已加载的小组列表，在「查看成员」上按 Enter。两次测量都拦截额外的列表 GET，如有该请求则在成员资料已可见后继续扣住至少 700 ms。成员详情 GET 正常请求本地服务。

| 视口 | 额外列表 GET 改前 → 改后 | 按 Enter 到详情标题获得焦点，改前 → 改后 |
| --- | --- | --- |
| 1280×850 | 1 → 0 | 1102 → 70 ms |
| 320×640 | 1 → 0 | 856 → 59 ms |

这些数值来自单次受控对照。改前，资料已可见时列表仍在转圈，键盘焦点还没到资料标题。改后，列表和邀请可继续使用，焦点在资料准备好后进入标题。窄屏截图滚动到了标题，列表仍保留在它上方。

- 窄屏 [改前](assets/codi221/before-320.png) · [改后](assets/codi221/after-320.png)

生产构建的 Chrome 回归在两档宽度覆盖键盘切换小组、等待详情时保留其他行、详情 503 后重试、邀请空态、筛选无结果与清除、手动刷新、越界分页恢复并保留所选小组。另复测窄屏导航和三个项目资料流程，共 5 项通过。前端 482 项测试、lint 和 Vite 构建通过。

本轮未在 Chrome 中模拟小组写操作结果未知，也未覆盖物理触屏、读屏器及其他浏览器。
