# CODI-220 只读状态与正文空间

Chrome 158 通过 testB 打开隔离演示的「校园阅读节｜现场清单」。比较同一篇只读文档在同步后、尚未滚动时的画面。原横幅为 41px，与状态栏之间有 16px。

| 视口 | 第一段起点改前 → 改后 | 第三节标题可见高度改前 → 改后 |
| --- | --- | --- |
| 1280×850 | y=320 → 263px | 34 → 34px |
| 320×640 | y=255 → 198px | 31 → 31px |
| 320×480 | y=255 → 198px | 0 → 31px，完整可见 |

- [桌面改前](assets/codi220/before-1280-850.png) · [改后](assets/codi220/after-1280-850.png)
- [短窄屏改前](assets/codi220/before-320-480.png) · [改后](assets/codi220/after-320-480.png)
- 同文档在线时显示「只读 · 内容已同步」。通过另一隔离账号真实降权后，键盘输入无法写入，服务端正文和版本保持原样。查找与匹配可用，Esc 回到查找按钮。空白只读文档仍显示状态和「正文当前只读」。
- 两档浏览器离线时显示「只读 · 等待同步」，仍可读已加载正文。在线协作者区收起时正文仅上移约 3px。重连后恢复同步状态。[短窄屏等待重连](assets/codi220/offline-320.png)
