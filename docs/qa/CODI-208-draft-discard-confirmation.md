# CODI-208 丢弃未同步草稿复验

用 Chrome 1280×850 和 320×640 实际编辑合成文档，拦住 WebSocket 提交后断网关闭标签。重新打开时浏览器保留一份未同步草稿。改前，在恢复面板对「丢弃本地草稿」按一次 Enter 会直接删除这份记录。

| 场景 | 最终结果 | 证据 |
| --- | --- | --- |
| 打开确认 | 显示草稿可能含未同步修改及丢弃后果。默认键盘焦点在「保留草稿」，320px 按钮高 44px，确认操作在首屏。 | [桌面改前](assets/codi208/before-1280.png) · [桌面改后](assets/codi208/after-1280.png) · [窄屏改前](assets/codi208/before-320.png) · [窄屏改后](assets/codi208/after-320.png) |
| 保留或取消 | 保留按钮和 Esc 均回到原入口，原草稿逐字保留。实际下载的纯文本含未同步文字，生产回归继续恢复草稿并验证另一浏览器看到同样正文。 | [窄屏保留后下载](assets/codi208/kept-320.png) |
| 槽位、登录或存储变化 | 在确认期间分别改写合成草稿、切换捕获的登录账号、模拟浏览器拒绝删除。均显示可见反馈，仍保留对应的存储内容。 | [窄屏槽位变化](assets/codi208/changed-320.png) · [窄屏拒绝删除](assets/codi208/storage-denied-320.png) |
| 继续确认丢弃 | 复原测试条件后明确激活确认。仅选中的本地草稿被移除，同一文档另一槽位逐字保留，服务端正文未含测试未同步文字。 | 两档浏览器断言 |

测试仅操作本轮合成草稿和合成文档。未覆盖实体触屏、读屏器和其他浏览器。
