# CODI-222 项目列表与项目资料独立加载

在隔离环境用 Chrome 和合成个人项目测量。从已完成加载的列表按 Enter 打开项目，保持详情 GET 直连本地服务。如果出现额外的列表 GET，等详情可见后仍扣住该请求至少 700 ms。

| 视口 | 额外列表 GET 改前 → 改后 | 按 Enter 到详情标题获得焦点，改前 → 改后 |
| --- | --- | --- |
| 1280×850 | 1 → 0 | 998 → 261 ms |
| 320×640 | 1 → 0 | 822 → 66 ms |

这是一组受控样本。改前，资料可见时项目列表仍显示加载，焦点留在原位置。改后，项目列表保留，标题进入视口。窄屏画面已滚到详情，项目列表可向上查看。

- 桌面 [改前](assets/codi222/before-1280.png) · [改后](assets/codi222/after-1280.png)
- 窄屏 [改前](assets/codi222/before-320.png) · [改后](assets/codi222/after-320.png)

在两档宽度的生产构建上验证：键盘打开详情；详情慢时保留列表；筛选和重试详情只读该项目；列表 503 后重试时保留已加载详情；列表和项目内文档都从越界页恢复到第 1 页，各自只重读一次。复测加入已有文档后的结果提示、从编辑器返回时聚焦原文档、小组打开成员及窄屏导航，Chrome 共 6 项通过。前端 482 项、lint、Vite 构建通过。

本轮未在真实浏览器验证小组归属项目的权限变化、物理触屏、读屏器及其他浏览器。
