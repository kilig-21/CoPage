# CODI-234 临时备份后继续浏览

隔离 Chrome 使用合成文档。暂缓协作写操作，并对本地草稿存储键注入写入失败。从带「我创建的」筛选和「校刊」关键词的文档列表打开编辑器，输入未同步文字后返回列表。

| 视口 | 改前 | 改后 |
| --- | --- | --- |
| 1280×850 | 焦点留在页面，点击继续跳到登录 | 焦点落在备份标题，继续后回到原列表 |
| 320×480 | 焦点留在页面，点击继续跳到登录 | 首屏可见下载入口，继续后回到原列表 |

两档都从标题按 Tab 移到富文本下载，按 Enter 取得包含未同步正文的文件。继续后，列表保留原筛选和中文关键词。320×480 另用第二个标签页登录另一个合成账号，备份页保留原正文，动作更新为「已备份，继续登录」，按 Enter 后进入登录表单。
