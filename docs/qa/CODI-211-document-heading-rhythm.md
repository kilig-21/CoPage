# CODI-211 文档正文章节层级复验

使用隔离演示库中的同一份「校园阅读节｜活动方案」和只读「现场清单」。Chrome 158 测试桌面 1280×850 和窄屏 320×640。测量使用渲染后的相邻正文盒，预览在切换动效结束后采样。

| 检查项 | 改前 | 改后 |
| --- | --- | --- |
| 编辑、只读、历史及打印预览的节间距 | 0px | 前一段后 16px、标题后 4px |
| 窄屏编辑器样例二级标题 | 24px，最后一字落到第二行 | 22px，样例在一行显示；更长的标题仍正常换行 |
| 窄屏横向滚动 | 页面与正文均无 | 页面与正文均无，包括连续中英文长标题 |
| 故意插入的空行 | 约 28.8px | 保留原高度，空行后不叠加 16px；列表后有 16px |

- 其他阅读场景：[历史改前](assets/codi211/before-history-320.png) · [历史改后](assets/codi211/after-history-320.png) · [只读](assets/codi211/after-read-only-320.png) · [打印预览](assets/codi211/after-print-1280.png) · [显式空行与长标题](assets/codi211/blank-line-320.png)。
- 两档都打开空文档，用键盘增加两段并保留一行空白，用真实详情接口核对已保存 Delta。浏览存量样例后使用该接口核对原 Delta 和版本。
- 历史、打印预览请求分别在两档注入一次 503。看见加载和失败提示，再用 Enter 重试真实请求。打印预览就绪后，以 Chrome 的 A4 PDF 导出验证打印树可渲染，并确认节标题设置了避免紧随分页。

未覆盖系统打印对话框、实体触屏、系统输入法和其他浏览器。打印分页规则由目标浏览器解释。
