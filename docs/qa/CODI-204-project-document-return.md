# CODI-204 返回项目的文档位置

在隔离预览 Chrome，打开包含八条匹配「场地交接记录」的项目，选择末条文档 #93，进入编辑器后按「返回项目」。#94 与 #93 同名。改前焦点回到项目标题，原行在两档都超出视口。改后通过文档编号定位标题链接，原筛选保留。

| 视口 | 原文档标题顶部 | 结果 | 证据 |
| --- | --- | --- | --- |
| 1280×850 | 887 → 676px | #93 完整可见且获得焦点 | [改前](assets/codi204/before-1280.png) · [改后](assets/codi204/after-1280.png) |
| 320×640 | 1894 → 356px | #93 完整可见且获得焦点，同名 #94 仍可辨认 | [改前](assets/codi204/before-320.png) · [改后](assets/codi204/after-320.png) |

两档另复验真实第二页。项目含 21 条关联，返回后仍是 `docPage=2`，焦点到 #81。项目详情读取返回 HTTP 503 时聚焦项目标题，重试恢复真实详情。故意挂起详情请求时，在项目名称输入框继续输入，迟到的回复未移动焦点或覆盖输入。仅在一处专用合成项目从另一请求移出 #93 的关联，返回时原编号已不可见，焦点落到项目标题，仍在结果的同名 #94 不会获得焦点。
