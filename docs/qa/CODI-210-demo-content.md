# CODI-210 本地协作样例复验

使用独立 Compose 项目 `copage-demo-210`、空数据库和既有本地后端镜像。原有预览继续运行。本轮使用 Chrome 158，桌面为 1280×850，窄屏为 320×640。

| 场景 | 浏览器和请求结果 | 画面 |
| --- | --- | --- |
| 空库首次登录 | 登录页两个演示按钮均能填入凭据并进入工作台。testA 与 testB 都显示最近文档为空。 | [桌面](assets/codi210/before-1280.png) · [窄屏](assets/codi210/before-320.png) |
| 导入并再次执行 | 首次导入三篇，第二次保留原三个编号。工作台真实请求返回 testA 拥有 3 篇、testB 收到 2 篇。两档均可用键盘打开全部文档。 | [桌面](assets/codi210/home-1280.png) · [窄屏](assets/codi210/home-320.png) |
| 正文检索与失败恢复 | 两档分别验证无匹配、请求等待和模拟 503。用 Enter 重试后走真实搜索，正文「报名」返回 testA 3 篇、testB 2 篇。两会话从编辑器用 Enter 返回时，焦点回到原搜索结果。 | [桌面](assets/codi210/search-1280.png) · [窄屏](assets/codi210/search-320.png) |
| 实时写入与权限 | testB 在 320px 输入，testA 在 1280px 立即看到。保存后真实详情请求的版本递增 1。「现场清单」阻止键盘修改且服务端正文不变。testB 请求「筹备会议」收到 403。 | [桌面](assets/codi210/editor-1280.png) · [窄屏](assets/codi210/editor-320.png) · [只读](assets/codi210/readonly-320.png) |
| 保留后续使用状态 | 在隔离库暂时移除 testB 的只读授权、将筹备会议移入回收站并重跑。脚本保留撤权、回收站状态和刚保存的正文及版本。检查后在隔离库恢复原权限、文档和样例正文。 | HTTP 与 CLI 断言 |
| 脚本错误反馈 | 公网形式地址在发请求前被拒绝。未监听的本地端口提示核对后端，两者均退出为 1。 | CLI 断言 |

截图经真实 Chrome 采集。窄屏检查包含工作台、文档列表、搜索及编辑器无横向溢出。未覆盖实体触屏、其他浏览器、默认 Docker 镜像重新构建及公网环境。
