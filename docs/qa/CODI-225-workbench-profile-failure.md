# CODI-225 账号资料失败时保留最近文档

用 Chrome 通过隔离演示账号 testA 登录。扣住账号资料 GET，等「最近文档」中「校园阅读节｜活动方案」可测后，注入 503。在相同视口记录标题的纵向位置和可见高度。键盘重试发出真实 GET 并确认恢复。

| 视口 | 改前，等待 → 503 后 | 改后，等待 → 503 后 |
| --- | --- | --- |
| 1280×850 | y=455 → 527px | y=491 → 491px |
| 320×640 | y=463 → 572px | y=499 → 499px |
| 320×480 | y=407 → 516px，标题可见高度 24 → 0px | y=439 → 439px，标题可见高度保持 24px |

问候先使用当前登录用户名，读取成功后换成昵称，占同一行。账号失败提示和重试放在最近文档后。保持在重试按钮上的键盘焦点在成功后到达问候语；若用户已移到其他控件，则保留该位置。

生产构建 Chrome 5 项覆盖账号资料慢请求和注入 503、重试加载状态、焦点、打开和返回最近文档，并复测登录、窄屏导航、新文档和搜索换页。前端 482 项、lint 和 Vite 构建通过。本轮未覆盖物理触屏、读屏器或其他浏览器。
