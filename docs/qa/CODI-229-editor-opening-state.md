# CODI-229 正文读取与保存状态

Chrome 通过隔离演示账号 testA 从工作台打开「校园阅读节｜活动方案」。暂停正文 GET，捕获初次读取画面。再注入一次 503，按 Enter 重试，暂停第二次 GET 并观察焦点，随后放行真实响应。

| 视口 | 等待时改前 | 等待时改后 | 按 Enter 重试后的焦点 |
| --- | --- | --- | --- |
| 1280×850 | 「加载中」「等待同步」，画布隐藏 | 「正在读取正文…」，显示静态画布 | BODY → 文档内容 |
| 320×480 | 「加载中」「等待同步」，画布隐藏 | 「正在读取正文…」，显示静态画布 | BODY → 文档内容 |

读取期间画布标记为忙碌，真实正文和编辑控件隐藏。503 显示原有失败原因与重试。重试时的焦点提示留在状态栏一带。若等待期间主动移动焦点，正文返回后保留该位置。
