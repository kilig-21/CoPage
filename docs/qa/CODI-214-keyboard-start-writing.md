# CODI-214 键盘新建后开始写作

用隔离合成账号在 Chrome 158 的工作台按 Enter，进入同样的空白文档后等到协作同步完成。测量首次写入之前从初始焦点到「文档正文」需要的 Tab 次数。

| 视口 | 改前 | 改后 | 画面 |
| --- | --- | --- | --- |
| 1280×850 | 19 次，初始焦点在页面主体 | 0 次，正文已获得焦点 | [改前](assets/codi214/before-1280.png) · [改后](assets/codi214/after-1280.png) |
| 320×640 | 8 次，初始焦点在页面主体 | 0 次，正文已获得焦点 | [改前](assets/codi214/before-320.png) · [改后](assets/codi214/after-320.png) |

- 两档可以立即输入，保存后真实详情接口返回相同正文，Shift+Tab 可以离开。生产浏览器回归覆盖工作台 Enter 和我的文档 Space，刷新后原文保留。[已写入并保存](assets/codi214/saved-320.png)
- 两档拦截新文档的第一次同步，按 Tab 先移到「返回工作台」，放行真实同步后该控件仍有焦点。[窄屏同步](assets/codi214/sync-320.png)
- 两档注入一次创建 503，原页面显示待确认反馈。Enter 重试走真实请求并可直接写入。真实创建且丢弃成功响应后，通过「确认原创建」回到原文档，正文焦点维持普通打开行为。[窄屏失败反馈](assets/codi214/failure-320.png)
- 桌面鼠标、窄屏浏览器触摸模拟、重开旧空文档、刷新、浏览器后退再前进均保持普通打开行为。两档无横向溢出。

Chrome 对生产构建运行本次交互及相关创建、导航回归共 7 项，全部通过。前端 482 项测试、lint 和 Vite 构建通过。未覆盖物理触屏、系统输入法、读屏器和其他浏览器。

失败后迅速重试时，上一条错误提示可短暂盖住窄屏标题。另行追踪提示生命周期。
