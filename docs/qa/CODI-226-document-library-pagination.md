# CODI-226 我的文档翻页后的键盘位置

在隔离环境为同一合成账号创建 22 篇匹配标题的文档。Chrome 打开「我的文档」，保留「我创建」和标题筛选，滚到第一页末尾并按 Enter 翻页。暂缓第二页请求，记录等待和就绪时的焦点。

| 视口 | 等待中的焦点，改前 → 改后 | 第二页就绪后的焦点，改前 → 改后 |
| --- | --- | --- |
| 1280×850 | BODY → 文档列表 | BODY → 文档列表 |
| 320×640 | BODY → 文档列表 | BODY → 文档列表 |

两档就绪后第一次 Tab 都到第二页第一篇。失败后可用 Tab 到「重试文档列表」，同样从列表继续。等待期间隐藏上一页的文档链接，自动纠正越界页时保留用户在筛选输入的焦点。

试着从工作台打开越界页再按浏览器后退，两档改前都再次进入文档列表，改后一步回到工作台。系统更正页码时替换原地址，主动翻页仍保留历史。
