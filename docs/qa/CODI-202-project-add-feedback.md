# CODI-202 项目文档加入结果复验

隔离环境 Chrome 1280×850、320×640，从个人项目加入同一份合成文档「映照记录」#84。改前两档关闭弹窗后都落焦到页面主体，320px 提示文字顶部为 -383px。打开已有标题筛选的项目时，新关联的文档可能不在当前筛选结果里。

| 场景 | 实测结果 | 证据 |
| --- | --- | --- |
| 正常加入 | 项目详情内显示标题、编号及打开入口，焦点进入结果区域。Tab 后 Enter 打开 #84 并读到原正文。窄屏结果区域完整位于 y=131–267，固定顶栏底边 y=115。 | [桌面改前](assets/codi202/before-1280.png) · [桌面改后](assets/codi202/after-1280.png) · [窄屏改前](assets/codi202/before-320.png) · [窄屏改后](assets/codi202/after-320.png) |
| 保留筛选 | 既有「活动日程」筛选和列表空状态保留，结果入口仍能打开实际文档。 | [窄屏筛选改前](assets/codi202/before-320-filter.png) · [窄屏筛选改后](assets/codi202/after-320-filter.png) |
| 已确认但详情读失败 | 挂起写成功后的详情请求，两档先显示已确认结果与刷新状态，返回 HTTP 503 后继续显示原确认和独立重试。重试恢复真实详情。再次主动进入项目仍聚焦项目标题。 | [窄屏读取中](assets/codi202/read-pending-320.png) · [窄屏读取失败](assets/codi202/read-failed-320.png) |
| 写响应丢失 | 后端实际新增关联，浏览器收到模拟 503。界面进入待核对，未显示成功；从弹窗核对后，真实状态接口返回原文档关联。 | [窄屏待核对](assets/codi202/unconfirmed-320.png) |
| 关联已存在 | 候选打开后从另一请求先加入同一文档，再用界面提交。真实响应 `changed=false`，界面显示「文档已在项目中」，项目仍仅一条关联。 | [窄屏已有关系](assets/codi202/already-present-320.png) |

两档跑了实际项目、同一原文档和键盘流程。故障验收桌面正常动效、窄屏减弱动效。前端回归覆盖筛选保留、正确编号和键盘打开。未覆盖读屏、实体手机或加入后恰好被撤权的真实竞态。
