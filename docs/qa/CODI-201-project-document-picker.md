# CODI-201 项目资料选择器复验

从个人项目打开「加入已有文档」，改前七个「加入项目」按钮同名，按 Esc 后焦点落到页面主体。首屏对照用同一隔离账号、项目和七条真实候选。在 320×640 中，首条加入按钮底边由 518px 提到 395px，操作由两行变为一行，第二条标题进入视口。首屏对照后微调了操作间距与错误反馈，下表中的同名候选和状态图采自最终源码。

| 场景 | 实测结果 | 证据 |
| --- | --- | --- |
| 首屏 | 将说明合为项目名和一句权限说明，筛选框直接可用，文档行先列加入、再列另开查看。 | [桌面改前](assets/codi201/before-1280.png) · [桌面改后](assets/codi201/after-1280.png) · [窄屏改前](assets/codi201/before-320.png) · [窄屏改后](assets/codi201/after-320.png) |
| 同名候选 | 两条同名文档保留编号、所有者和权限。加入及另开查看的可访问名称包含标题和编号。320px 两项操作同排，触达均为 44px。 | [桌面](assets/codi201/same-title-1280.png) · [窄屏](assets/codi201/same-title-320.png) |
| 筛选和关闭 | 两档打开后聚焦筛选。正常或名单读取中按 Esc 均回原发起按钮。筛选无结果时清除筛选，焦点回输入框，真实候选重新列出。 | [窄屏加载](assets/codi201/loading-320.png) · [窄屏无结果](assets/codi201/filtered-empty-320.png) |
| 读取失败 | 候选请求返回 HTTP 503 时显示重试入口，无候选操作。键盘重试读取到真实后端结果。 | [桌面](assets/codi201/error-1280.png) · [窄屏](assets/codi201/error-320.png) |
| 关联及权限 | 1280×850 将只读文档加入个人项目，320×640 加入自己拥有的另一份同名文档。另开查看打开各自编号，真实项目响应只列所选文档，前后核对正文、修订号及协作者结果相同。同组候选请求只返回自己拥有的文档。 | [窄屏小组](assets/codi201/group-320.png) |

桌面手验使用正常动效，窄屏启用减弱动效。生产构建 E2E 持续覆盖两档的筛选焦点、无结果清除和 Esc 回焦。未覆盖实体触屏、实际读屏、候选分页和项目写入超时。
