# CODI-227 恢复文档后用键盘打开

用隔离环境创建合成文档并移入回收站。在 Chrome 按 Enter 确认恢复，暂缓真实恢复请求，记录就绪前后的焦点。恢复成功后比较打开入口的位置，使用 Enter 继续。

| 视口 | 等待时的焦点 | 成功后的焦点，改前 → 改后 |
| --- | --- | --- |
| 1280×850 | 确认恢复 | BODY → 打开文档 |
| 320×640 | 确认恢复 | BODY → 打开文档 |

- 桌面 [改前](assets/codi227/before-1280.png) · [改后](assets/codi227/after-1280.png)
- 窄屏 [改前](assets/codi227/before-320.png) · [改后](assets/codi227/after-320.png)

两档都用 Enter 打开了同一 ID 的文档，生产构建复验了原正文和回收站空态。在窄屏等待中将焦点移到工作台链接，正常响应保留该位置。让真实恢复在服务端完成、向页面返回注入 503 时，仍需显式核对；读取原文档状态后才能从结果打开。

生产构建 Chrome 共 5 项通过，另复测文档菜单、列表翻页和工作台失败恢复。前端 482 项测试、lint 和 Vite 构建通过。未覆盖物理触屏、读屏器及其他浏览器。
