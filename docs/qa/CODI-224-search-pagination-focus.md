# CODI-224 搜索翻页的键盘位置

在本机隔离环境用 Chrome 搜索 12 篇合成文档，将第一页滚到底，按 Enter 激活「下一页」，暂缓第二页请求。两档视口分别在等待期间和第二页内容就绪后读取焦点。恢复网络后再用 Tab 继续。

| 视口 | 第二页请求期间的焦点，改前 → 改后 | 第二页就绪后的焦点，改前 → 改后 |
| --- | --- | --- |
| 1280×850 | BODY → 搜索结果区 | BODY → 搜索结果区 |
| 320×640 | BODY → 搜索结果区 | BODY → 搜索结果区 |

两档翻页后第一次按 Tab 都到达第二页第一篇文档。多页结果的状态行显示当前页和总篇数，窄屏单行放下「第 2 页 · 共 12 篇」。焦点边框标出键盘所在区域。
