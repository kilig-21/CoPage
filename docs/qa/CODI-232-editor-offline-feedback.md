# CODI-232 编辑器离线与待同步反馈

用隔离 Chrome 打开合成的可编辑文档。先在空白正文模拟浏览器离线；恢复后写入一句话，暂缓这条写操作，再次离线检查状态。最后恢复真实连接并读取服务端正文与版本。

| 场景 | 改前 | 改后 |
| --- | --- | --- |
| 浏览器离线，空白正文 | 「正在重连」「等待同步」「正文当前只读」 | 「已离线」「暂不可编辑 · 等待同步」「暂无正文」 |
| 浏览器离线，已有未确认写入 | 「正在重连」「有修改尚未同步」 | 「已离线」「暂不可编辑 · 有修改尚未同步」 |
| 浏览器在线，协作连接中断 | 「正在重连」 | 「正在重连」 |

1280×850 和 320×480 都保留同一段未确认正文，离线期间新增输入被阻止。重连后服务端收到原句，版本从 0 到 1，编辑可继续。关闭中的格式工具在暂停时禁用，展开中的工具仍可收起。另复测权限只读文档在离线时仍标明只读。

生产构建 Chrome 6 项通过，覆盖真实协作、掉线重连、草稿、只读、格式工具和文档加载。前端 482 项、lint、Vite 构建通过。离线和传输中断使用浏览器控制，未覆盖物理手机、实际读屏器及其他浏览器。
