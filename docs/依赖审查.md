# 发布依赖审查

## 2026-10-04 前端

发布检查通过官方 npm 审计接口发现原锁文件中8个受影响依赖（5高、2中、1低）。已将 Axios 更新到1.20.0、React Router DOM更新到7.18.4、Vite更新到7.3.6、React插件更新到5.2.0；版本均精确锁定。React继续18.3.1，Node要求22.12以上（本机验收24.16.0）。

当前锁文件执行以下命令：0高危、0中危、1低危，退出码0。

```powershell
npm --prefix frontend audit --registry=https://registry.npmjs.org --audit-level=moderate
```

剩余项为[Quill HTML导出公告](https://github.com/advisories/GHSA-v3m3-f69x-jf25)，上游尚无标记为已修复的新版本。[发现者说明](https://fluidattacks.com/advisories/diomedes)中的触发条件是formula/video的HTML序列化结果被作为HTML再次渲染。应用代码没有直接调用`getSemanticHTML/getHTML`，但Quill自身复制/剪切的`Clipboard.onCopy`内部会调用`getSemanticHTML`写入系统剪贴板，不能将该内部路径描述为完全没有调用。前端编辑器和历史/模板预览共用`DOCUMENT_FORMATS`，排除formula/video；后端实时操作与副本导入也拒绝这些嵌入。应用没有将HTML导出结果写入`innerHTML/dangerouslySetInnerHTML`；正文预览通过`setContents`读取Delta，导出由Java生成JSON/纯文本。导入仅接受文字与HTTP(S)图片，不接收formula/video。此结论只覆盖当前使用路径，不表示Quill本身零漏洞。后续引入HTML导出或其他嵌入类型前，必须重新评估，不能使用`audit fix --force`为消除报告而盲目降级。

升级依据：[React Router 7迁移说明](https://github.com/remix-run/react-router/blob/react-router%407.18.4/docs/upgrading/v6.md)、[Vite 7迁移说明](https://v7.vite.dev/guide/migration)。项目使用声明式BrowserRouter、顶层lazy及绝对内部路由，没有数据路由或多段splat依赖。保留按路由加载和API/WS本地代理。

验证：前端26项回归、生产构建通过（最大JS块293.88 kB）；真实Edge使用生产产物完成模板创建文档120、授权第二账号、双向编辑及刷新保留、图片multipart上传并在另一账号加载、退出后通过原文档链接重新登录返回、实际JSON副本下载。当前生产预览使用新Vite启动。
