# CoPage 界面方向与首轮体验验收

日期：2026-10-10。负责人确认“清爽编辑部”为主、“现代工作室”为辅，允许简单动效。沿用现有CoPage、Ant Design、图标和路由，不重搭。Awwwards、Webby Awards、FWA是品质参照，不代表已经获奖或全部达到评审水平；完整功能、权限和内容保留继续优先。

## 当前设计约定

- 纸白背景、墨色正文、克制蓝色操作。正文与说明使用系统无衬线字体；品牌和页面标题采用现有系统衬线字体，避免为装饰增加远程字体或位图。
- 内容最大宽1120px，桌面留64px总边距、手机32px；用标题、区域和间距区分任务，近期资料优先于组织统计。
- 资料页面共用CoPage品牌、七个主入口和当前页标识。窄屏保留可滚动主导航，账户、指南和退出用有可访问名称的44px图标按钮，页面操作另行排列。
- 主要操作使用真实Button或链接。文档标题/打开优先，副本、模板、改名和成员管理收进“更多”；删除保留独立危险操作及确认。所有者、可编辑和只读权限仍决定原有入口。
- 悬停/状态过渡约160ms，不添加妨碍阅读的持续运动；prefers-reduced-motion降低过渡。移动文档操作和可见回收站页码/前后页控件保持44px高度。
